## 읽기 화면

- 새 판의 본문과 선택 후 `outcome.narrative`는 CRLF를 정규화하고 빈 줄로 문단을 나누어 실제 `<p class="story-paragraph">`로 렌더링한다. 줄 간격 1.75, 문단 간격 1.15em을 적용한다. 본문에 포함된 대사를 화자 카드로 다시 출력하지 않는다. 원작의 presentation 화자 카드는 유지한다.
- 기본은 문단을 천천히 자동 표시한다. 메인창 클릭은 다음 문단 하나를 즉시 표시하고 기본 자동 속도를 이어간다. 스킵은 현재 표시를 완료한다. 읽기가 끝난 다음 선택 팝업을 열며, 내리기/복원/일시정지/빠르게/설정은 유지한다.
- 실제 선택과 저장을 먼저 한 번 처리한다. 그 결과의 후속 서술을 보여주고 읽기가 끝난 뒤 다음 사건의 나이·본문·선택을 표시한다. 후속 서술 중에는 다음 사건과 선택을 노출하지 않는다. 렌더링·스킵으로 엔진이나 RNG를 재실행하지 않는다.
- 위쪽 최근 연대기는 방문 노드의 독립 `chronicleSummary`와 나이만 한 줄로 표시한다. 본문 발췌나 대사를 넣지 않는다. 긴 요약은 말줄임표와 `title`로 제공한다. 전체 높이 `clamp(72px, 16vh, 130px)`와 내부 스크롤을 적용했다. 기본 최근 3개/전체 기록 및 실제 방문 순서를 유지한다.
- 기존 레이아웃은 위쪽 최근 기록과 아래쪽 본문이 전체 폭을 사용하는 구조다. 35:65 열 분할을 새로 만들지 않고 연대기의 높이를 줄여 본문에 공간을 배정했다. 본문은 내부에서 스크롤하며 선택지까지 접근 가능하다. 과거 사건을 다시 불러올 때에는 요약/실제 선택만 표시한다.
- 기존 100~150% 전체 글자 크기 설정, 초상화/능력치/NPC 영역과 저용량 WebP를 유지한다. 새로운 회상 그림은 간단한 코드 SVG여서 추가 비트맵 다운로드가 없다. 엔딩 SVG는 일반 20px 아이콘 규칙을 덮어쓰고 비율에 맞게 표시한다.

## 엔딩과 저장

- `ending_cinematics.json`을 별도 스키마로 로딩한다. 7개 결말 모두 마지막 서술 → 실제 경험 회상 → 독백 → 엔딩 카드의 독립 화면을 사용한다. 사용자에게 단계 이름/번호를 표시하지 않는다. 결말 화면에서는 게임 HUD를 숨긴다.
- 회상은 실제 `history`에서 첫/마지막/핵심 사건을 최대 8개 골라 시간순으로 표시한다. 미방문 사건을 보충하지 않는다. 회상은 천천히 자동 또는 클릭으로 넘기며, 마지막 서술/독백은 버튼으로 진행한다. OS 움직임 줄이기에서는 회상 자동 넘김/애니메이션을 끈다.
- 결말 카드까지 도달한 뒤에만 도감을 해금한다. 새로고침 복원과 중복 해금 방지를 검증했다. 결말 로더가 실패하면 기존 종료 화면으로 안전하게 돌아간다.
- 원작의 회차 키 `existence-sim:v1:run:demon-king`와 기존 공용 도감 키를 변경하지 않는다. 새 판은 `existence-sim:v1:run:demon-king:compact` / `existence-sim:v1:meta:demon-king:compact`에 별도로 저장한다. 원작/축소판 간 JSON 가져오기를 거부하고 해당 판으로 전환하도록 안내한다. 원작 구 세이브 복원/백업은 유지한다.
- 표시 위치만 별도 `demon-king:compact-view:<runId>` 키로 저장한다. 후속 서술 완료 위치와 결말 화면/회상 위치를 복원한다. 게임 세이브 계약에는 표시 필드를 추가하지 않았다. 저장 제한이나 손상으로 이 표시 키가 유실되면 서술을 다시 읽을 수 있으나 선택/효과/재산을 중복 실행하지 않는다.

## 데이터 보호와 한계

- 실행 JSON 5개는 최신 ZIP과 바이트 단위로 일치한다. 원작 JSON 8개는 적용 전 `backups/before-content-v2/`와 바이트 단위로 일치한다. SHA-256/분기 결과는 `compact-import-report.json`에 기록했다.
- 기존 조건·가중치·효과·ID·목적지를 보존한다. 새 판에 한정한 메모리 복사 어댑터로 원본의 조기 종료 `result:bad` 4개를 기존 계약 `failure`로, 엔딩 `kind:good`을 `happy`로 대응시킨다. 결과 분류의 별칭만 변환하며 파일이나 판정 결과를 바꾸지 않는다. 스키마의 기존 4개 결과 열거형을 확장하지 않았다.
- 첫 사건은 출생 0세인데 원본 initialState.age는 20이다. 시작 시 실제 노드 나이를 동기화하라는 동봉 지침을 적용했다. 이후 시간 역행 검사와 저장 원장/seed 재현은 유지한다.
- **콘텐츠 상태 효과 누락:** 합의금 5만 금화는 원문에 플래그만 있고 gold 효과가 없다. 감옥 장면의 유죄 서술에도 crimes/legalStatus 효과가 없고 사망 서술에도 alive 효과가 없다. 따라서 수치·범죄 목록·alive는 서술과 일치하지 않을 수 있다. 이를 임의로 추측해 효과를 추가하지 않았다. 작가의 명시적 효과/정사 업데이트가 필요한 항목이다.
- 0→12→20→21→29→41→47→60/62/65의 연령 간격과 합류 장면의 과거 플래그 미반영은 원문에 존재한다. 빈 해의 서사를 새로 만들거나 전체 98장면의 집필 완료로 보고하지 않는다.

## 해결 기록

- Playwright 테스트에서 엔진 모듈을 직접 가져오면 Node ESM의 Ajv import 해석이 달라졌다. 테스트의 불필요한 엔진 import를 제거하고 실제 UI/원본 JSON fixture로 검증했다. 앱의 Ajv 설정을 완화하지 않았다.
- 테스트 초기화에서 타이틀의 `isVisible`을 너무 일찍 확인해 실행 버튼을 놓쳤다. 기존 테스트와 같은 sessionStorage 초기화/활성 버튼 대기로 고쳤다. 실제 앱 문제로 오인해 렌더러를 재작성하지 않았다.
- save.schema.json은 기존 CRLF에서 LF로 정규화되어 큰 포맷 diff가 있다. 의미 변경은 버전의 prerelease 문자열 허용 한 곳뿐이다. 저장 필드/기존 버전 지원은 유지한다.
- 스크린샷에서 엔딩 그림이 20px 높이로 보인 원인은 전역 svg 아이콘 규칙이었다. `.compact-art`에 height:auto/비율을 적용하고 실제 그림 높이 검사를 추가했다.
