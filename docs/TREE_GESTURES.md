## 재현과 원인

- 수정 전 실제 노드에서80px 터치 드래그 시 처음12px만 이동했다. 입력을 노드에서 지도로 캡처 전환할 때 자식의 lostpointercapture가 버블링되고, 지도의 처리기가 정상 포인터까지 삭제했다.
- 노드 위에서 휠로1.822배 확대 후 누르면 노드 focus 처리의 center()가 배율을1로 초기화했다. 빈 공간 위주의 과거 검사는 이 경로를 다루지 못했다.
- [수정 전 회귀 검사3실패/터치 전용PC1제외](tree-gestures/baseline.log). 표준의 암묵적 캡처/해제·touch-action 규칙은 [W3C Pointer Events](https://www.w3.org/TR/pointerevents/)를 확인했다. 별도 라이브러리를 추가하지 않고 기존 브라우저 표준 처리를 보완했다.

## 변경

- src/ui/ending-tree.ts: 지도 캡처 단계에서 처음부터 포인터를 소유한다. 노드·글자·배경 어디서 시작해도 동일하게 처리하며 자식의 캡처 해제로 입력을 삭제하지 않는다. 미니맵은 기존 전용 입력을 유지한다.
- 8px 이내 탭은 손을 뗄 때 상세를 열고, 그 이상 움직이면 이동으로 판정한다. 두 손가락은 핀치가 우선이며 가운데를 기준으로 확대·축소한다. 제스처 후 남은 한 손가락/취소는 노드 클릭으로 처리하지 않는다.
- 기존250ms 클릭 차단 타이머를 없애 다음 정상 탭을 바로 받는다. 포인터의 후속 click 중복을 차단하되 키보드·보조기술 활성화와 노드 포커스 탐색은 유지한다.
- 동작 중 자동 중앙 이동을 막는다. 노드 위 휠도 지도에서 처리한다. CSS는 노드 touch-action과 지도 텍스트 선택 방지만 추가해 본문·상세 텍스트 조작에 영향을 주지 않는다.
- tests/e2e/tree-compact.spec.ts: 노드에서 시작하는 확대 상태의 드래그/미세 이동 탭/키보드, 실제 터치 다단계 드래그/핀치/한 손가락 잔류/취소/즉시 다음 탭 검사를 추가했다. 카메라 외 노드 위치·게임 저장/도감 원장 불변도 확인한다.
