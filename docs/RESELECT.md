# 지난 분기에서 이어하기

공개 앱과 바탕화면 실행은 최신 판을 기본으로 사용한다. 원작 플레이 버튼과 공개 원작 진입은 제거했다. 예전 `?edition=compact` 링크는 계속 동작하며 `?edition=original`도 현재 판으로 연결된다. 원작 세이브/도감/원본 파일 자체를 삭제하거나 새 판으로 변환하지 않았다.

## 사용

1. 메인 화면의 **전체 기록**을 열거나 최근 연대기의 사건을 누른다. 최근 사건을 누르면 해당 재선택 버튼으로 바로 이동한다.
2. 원하는 방문 사건에서 **여기부터 재선택**을 누른다. 현재 사건은 **이 사건 이어하기**로 표시한다.
3. 그 사건의 선택 직전 상태와 당시 나이를 복원하고, 읽었던 본문/선택지를 바로 펼친다. 이후의 선택/결말 기록은 새 선택에 맞춰 이어진다.
4. 후속 서술이나 엔딩 화면 중에는 **설정 → 지난 분기에서 이어하기**로 진입한다.
5. 재선택 이전 회차를 다시 보려면 같은 기록 메뉴에서 **재선택 전 회차 복원**을 누른다. 복원하기 전 회차도 다시 백업되므로 직전 두 경로를 오갈 수 있다.

대상은 현재 회차에서 실제로 방문한 사건이다. 미방문 사건이나 다른 회차 전체의 방문 목록을 해금하지 않는다. 발견한 엔딩 도감은 별도로 유지한다.

## 상태 보호

`resumeAtVisitedNode`는 원본 세이브 전체를 재검증하고 최초 seed로 선택 원장을 해당 사건 직전까지 실제 choose 함수로 재현한다. 능력치·관계·금화·법적 상태·범죄·플래그·소지품·나이·난수를 복원한다. 상태 효과를 역산하거나 결과를 강제하지 않는다. 동일 조건/seed에서 같은 선택을 하면 기존 확률 판정을 재현한다.

새 runId로 표시 위치/읽기 타이머를 분리한다. 재선택 전 상태는 `existence-sim:v1:backup:before-reselect:demon-king:compact`에 검증 가능한 전체 JSON으로 백업한다. 백업/저장 실패 시 원래 회차를 유지한다. 저장 재시도가 성공한 뒤에만 복원한 사건의 선택지를 연다. 최근 한 번의 백업만 유지하므로 저장량이 회차 수에 따라 무한히 증가하지 않는다.

## 검증

- 새 엔진/저장 검사는 관계·금화·전과 등 전체 상태 복원, 원본 불변, 가중치 판정과 난수 재현, 미방문/변조 거부, 백업 복원/손상/실패를 검사한다.
- PC·모바일 UI 검사는 재선택 → 다른 분기 → 새로고침 → 직전 회차 복원 → 출생 재선택과 종료 후 재선택/도감 유지/저장 실패 재시도를 검사한다.
- 전체 회귀 검사: 단위/통합108개, 현재 판20개+보관된 원작64개 브라우저 검사, 총192개. 원작 UI 검사는 별도 로컬 Vite `archived-ui` 모드에서만 가능하며 공개 production 빌드에는 원작 진입이 없다.
- 실제 빌드 검수는 `npx tsx scripts/verify-reselect-ui.ts http://127.0.0.1:4175/ --screenshots`로 PC1280px/모바일320·360·390·430px과 글자150%를 검사한다. `reselect-history-*`, `reselect-choices-*` 스크린샷을 남긴다. 실제 휴대폰/Safari/Firefox는 확인하지 않았다.
- 공개 주소 검수: `npx tsx scripts/verify-reselect-ui.ts https://jilzu001.github.io/demon-king-life/`.
