# 타이틀·인생 대화창·선택 팝업 — 2026-10-14

사용자가 GPT에서 스토리를 시험할 때 즐겼던 ‘연대기 한 줄 → 사건 대사 → 선택지’ 흐름을 기준으로 기존 화면만 개편합니다. 작가가 제공한 장면·대사·선택 설명을 사용하며 외부 GPT 호출이나 새로운 결과 생성은 없습니다.

## 화면과 조작

- 설정의 화면 전체 글자 크기 조절은 기본 크기 100%부터 최대 150%까지 10%씩 키웁니다. 모든 font-size와 상속 글꼴에 같은 배율을 적용하며 기본 크기보다 작아지지 않습니다. 초상화는 정사각형으로 유지하고, 연대기 나이 열은 커진 글자 폭에 맞추며 버튼과 팝업은 내부 줄바꿈/스크롤을 사용합니다. 화면 크기 설정은 `demon-king:ui:text-percent`로 저장하며 회차 세이브와 분리합니다.

- 게임 제목은 타이틀 화면에서만 표시합니다. 시작/이어하기 후에는 제목을 제거하고 상단에 주인공 정사각 초상화, 나이·전투력·마력·금화의 2×2 상태판, 오른쪽 NPC 영역을 표시합니다. 같은 탭의 새로고침에서 타이틀을 반복하지 않습니다.
- 사용자 확인대로 연대기 진행 중에는 오른쪽 NPC 영역만 배경 사진으로 바꿉니다. 사건 대사 단계에서는 제공된 대화에 등장하는 주요 인물의 초상화를 표시합니다. 현재 생존 상태를 확인하며 없는 인물을 추측으로 등장시키지 않습니다.
- ‘나의 인생’ 옆에 전체 기록 버튼을 둡니다. 최근 기록 3개는 대화창 위에 남겨 두고 한 줄로 표시합니다. 전체 요약·성장 기록은 대화창 또는 전체 기록에서 읽을 수 있습니다.
- 본문은 GPT 대화창처럼 연대기와 화자별 대사를 순서대로 천천히 자동 표시합니다. 약 6자/초, 최소 2.5초를 줄마다 기다립니다. 메인창 클릭은 다음 한 줄만 즉시 공개하며 기존 타이머를 취소하고 새 줄의 읽기 시간부터 자동 진행을 이어갑니다. 빠르게 모드에서 클릭해도 기본 자동 속도로 돌아갑니다. 마지막 대사의 읽기 시간이 지난 뒤 선택 팝업을 엽니다. 스킵은 즉시 선택 팝업을 엽니다. 연대기를 읽는 중에는 사건 제목·장소도 먼저 노출하지 않습니다.
- 팝업은 하단 조작부 위에 열리며 최근 연대기 아래의 공간 안에서만 높이를 사용합니다. 선택지가 길면 팝업 안에서 스크롤합니다. ‘잠시 내리기’/Escape는 팝업만 닫고, 인생 칸 아래 ‘선택지 보기’로 다시 엽니다. 원장·RNG·현재 장면은 바뀌지 않습니다.
- 하단에는 빠르게·스킵·일시정지/재생·인물·설정 버튼을 둡니다. 설정의 저장 내보내기·가져오기·새 회차·이전 저장 백업·34개 엔딩 도감은 유지합니다. 읽기 완료 후에는 읽기 조작만 비활성화합니다.
- 현재 사건만 대화 DOM으로 생성하며, 이전 사건은 위로 스크롤하거나 ‘이전 사건 불러오기’를 눌러 한 개씩 추가합니다. 이미 로딩한 JSON 캐시를 사용하며 실제 방문한 장면만 표시합니다. 과거의 선택·확정 결과도 같이 복원합니다. 스크롤 높이의 증가량을 보정하여 읽던 위치가 밀리지 않게 합니다.
- 화면은 `100dvh`와 안전 영역, 내부 대화 스크롤을 사용합니다. 특정 휴대폰의 해상도를 고정하지 않습니다. ResizeObserver로 팝업의 사용 가능한 높이를 실제 상단/하단 요소 크기에 맞춥니다.

## 이미지와 용량

아래는 초기 단일 초상화 적용 기록입니다. 최신 연령·감정 초상화는 ‘연령·감정 초상화 v2’ 항목을 사용합니다.

내장 imagegen으로 주인공·미나·에리시아·국왕·세렌 초상화 및 배경을 생성했습니다. 외형은 장식용 디자인이며 새 정사나 사건을 추가하지 않습니다. 원본은 Codex의 generated_images에 그대로 보존하고 웹 배포에는 작은 WebP 사본만 사용합니다.

사용자가 용량 축소를 요청하여 설치된 Sharp로 비율을 유지하며 웹용으로 인코딩했습니다. 초상화는 256×256, 배경은 1280×853입니다. 총 14,757,328바이트에서 195,516바이트로 98.68% 감소했습니다. 초상화는 각각 4~6KB, 배경은 약 169KB입니다. 새로운 앱 런타임 의존성은 없습니다.

출력 목록과 정확한 생성 프롬프트는 `art-prompts.json`, 파일별 크기는 `art-optimization.json`입니다. 원본 PNG는 public/Git 배포에 포함하지 않습니다. 재인코딩에는 `scripts/optimize-art.mjs`와 설치된 Sharp 패키지 경로를 사용합니다. AI 생성으로 디자인했고 파일 용량 축소에는 표준 이미지 인코딩을 사용했습니다.

## 작업 보호와 확인 이력

- 엔진·조건·확률·상태 효과·스토리 JSON·세이브/도감 스키마는 변경하지 않았습니다. 읽기·초상화·팝업·이전 사건 표시가 선택 판정을 호출하지 않습니다.
- 처음 이미지 복사에서 도구의 안내 문구 전체를 경로로 추출해 실패했습니다. 안내의 실제 파일 경로만 추출해 수정했습니다. 원본 파일은 항상 보존했습니다.
- 압축 도구의 기존 `lib/index.js` 경로를 가정해 실행이 실패했습니다. 설치된 Sharp 0.35.5의 package.json에서 진입점이 dist로 바뀐 것을 확인하고 패키지의 공식 진입점으로 로딩합니다. 압축 실패 후 작업 사본 PNG를 먼저 지운 실수는 보존한 원본에서 복원하고, 모든 WebP 생성·크기 확인을 마친 뒤 사본만 제거했습니다.
- 첫 새 UI 회귀 검사에서 선택 팝업이 열린 상태로 배경 안내를 클릭하려는 기존 검사가 실패했습니다. 실제 사용자 조작대로 ‘잠시 내리기 → 안내 열람 → 선택지 다시 열기’로 바꿨습니다. 모달의 배경 클릭 차단을 해제하거나 강제 클릭으로 숨기지 않았습니다.

## 검증

`tests/e2e/chat.spec.ts`는 타이틀의 최초 시작·저장 보호·제목 제거, HUD/이미지 전환/용량, 팝업 위 최근 기록, 팝업 내리기/복원, 방문한 과거만 한 사건씩 로딩, 하단 일시정지와 메뉴, 짧은 320×568 화면을 검사합니다. 기존 분기·저장·읽기 회귀 검사도 새 사용자 조작에 맞게 유지합니다.

실제 개발/빌드/공개 주소는 `npx tsx scripts/verify-chat-ui.ts <주소>`로 PC 1280×900, 모바일 390×844, 작은 화면 320×568에서 확인합니다. 캡처는 `chat-title-*`, `chat-reading-*`, `chat-choice-*`입니다. 실제 휴대기기와 Safari/Firefox는 별도 검증입니다.

## 연령·감정 초상화 v2

- 사용자가 여성 NPC를 확실히 구분하고 중요 인물의 4연령 × 5감정을 별도 이미지로 만들도록 요청했습니다. 미나는 짧은 비대칭 적갈색 머리·호박색 눈·갑옷, 에리시아는 긴 밝은 금발/땋은 머리·파란 눈·왕실 복장, 세렌은 검푸른 단발·안경·행정 복장으로 구분했습니다. 얼굴형도 다르게 제작했습니다.
- 주인공·미나·에리시아·국왕·세렌 각 20종, 요청한 감정 이미지 100종을 제공합니다. 감정이 지정되지 않은 대사를 위한 기본 표정 20종도 추가했습니다. 모든 파일은 별개이며 SHA-256도 120개 모두 다릅니다.
- 내장 imagegen으로 인물별 4열/6행 시트를 제작한 뒤 설치된 Sharp로 각 칸을 분리/인코딩했습니다. 배포에는 시트를 넣지 않습니다. 초상화 128×128, 품질 45 WebP, 전체 184,826바이트, 한 장 최대 2,106바이트입니다. 배경 포함 353,560바이트입니다.
- 초년/중년/장년/노년은 작품 진행 나이의 <35/<50/<65/65+ 화면 단계입니다. NPC의 실제 생년월일/연령 필드를 새로 만들지 않습니다. 원본의 생존 상태를 확인하여 사망한 NPC를 현재 화자로 표시하지 않습니다.
- 제공 대사 116줄의 연출 표정을 `src/ui/portraits.ts`에 연결했습니다. 현재까지 표시한 대사의 마지막 주요 NPC/주인공을 기준으로 표시합니다. 미제공/구 콘텐츠 대사에는 기본 표정을 사용합니다. 표정은 화면 연출이며 새로운 심리 상태·선택 결과·관계를 저장하지 않습니다.
- ES2022 타입 설정에서 Array.findLast가 지원되지 않아 타입 검사 1회 실패했습니다. 타깃을 높이지 않고 복사 배열의 reverse/find로 보완했습니다.
- 생성 프롬프트/원본 보존 경로는 `portrait-prompts-v2.json`, 개별 파일·크기·해시는 `portrait-assets-v2.json`입니다. 전체 초상화 확인은 공개 `art/portraits/gallery.html`에서 가능합니다. 원본 PNG는 Codex generated_images에 보존하며 쓰지 않는 v1 얼굴 파일은 배포에서 제거했습니다.
- 최종 `npm run check` 종료 코드 0: 단위/통합 98개, PC/모바일 브라우저 60개, 타입·콘텐츠·98장면/34엔딩 전수 분기·빌드 통과. 실제 공격 실패 뒤 미나의 화남→황당 표정과 주인공의 황당 표정, 원장 불변을 검사합니다. 실제 루트 빌드는 별도 실행 명령으로 확인합니다.
