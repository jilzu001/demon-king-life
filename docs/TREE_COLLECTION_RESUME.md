# 전체 분기·수집 경로·지난 회차 이어하기 — 2026-10-16

사용자 승인: 기존 도감 안의 트리를 전체44사건·119선택·결과 연결로 확장한다. 게임 본문 배치는 유지한다.

## 구현

- 대표20경로의 접두 트리101노드를 전체 선택/결과 DAG140노드(출발1+선택 결과119+엔딩20)·344연결로 교체했다. 동일 사건/선택으로 합류하는 곳은 공유하고 고정된 층별 위치에 배치한다. 91,664종단 경로를 개별 복제하지 않으며 전체 연결과 각 선택·판정 조건을 표시한다. 선이 이어져 있어도 실제 상태 조건을 통과해야 진행할 수 있다.
- 기존 이동/휠/두 손가락/미니맵·전체 보기·키보드·목표 찾기·잠금/옵트인 힌트를 유지한다. 미방문 분기 문구는 기존 힌트 설정을 켜면 공개하며 미획득 엔딩 그림·결말은 계속 숨긴다. 목표 파란색은 실제 검증된 수집 예시1개이며 모든 조건을 무시한 강제 진입 경로가 아니다.
- 청록색은 수집 경로(실제 회차 기록 우선, 기록이 없으면 검증 예시), 금색은 현재 회차의 실제 선택, 파란색은 목표다. 중첩 노드는 청록색 왼쪽 테두리와 금색으로 구분하고 연결선과 미니맵도 표시한다. 실제 원장에 없는 합류선은 금색으로 칠하지 않는다.
- 실제 방문한 사건 노드의 재선택 버튼→기존 확인→선택 직전부터 진행한다. 현재 회차가 방문한 사건이면 그 기록을 우선하고, 아니면 검증한 지난 회차를 사용한다. seed·선택·난수를 기존 재현 함수로 복원하며 능력/관계를 역산하지 않는다. 현재 진행은 기존 재선택 백업으로 보존한다.
- 새 회차/재선택/가져오기 전에 실제 회차를 별도 `tree-history` 키에 보관한다. 엔딩별 최근1회+최근 미완주1회, 최대21개/1MB로 제한하며 기존 회차·도감 스키마는 바꾸지 않는다. 재선택/가져오기/구버전 백업도 검증해 읽는다. 열기·카메라 조작은 저장을 쓰지 않는다.
- 손상된 기록은 초기화하지 않고 원본을 보존한다. 쓰기·읽기 검증·백업 실패 시 현재 회차를 교체하지 않는다. 과거 엔딩ID만 있고 실제 회차 원장이 없으면 색은 표시하지만 그 상태를 꾸며 복원하지 않는다.
