# v3.6 적용 범위와 검증

이 문서는 중간 단계2d0d037의 기록이다. 당시 빌드 수정 후 타입/콘텐츠/분기/빌드와 DPR1/2 각80개·총160조합까지 통과했다. 이후 v3.7 정체성 검수에서 나무칼 CG 사용을 보류하고 기준 초상화로 바꿨다. 현재 적용과 최종 검증은 [v3.7 보고서](V3_7_APPLY.md)를 기준으로 한다.

먼저 기존 AGENTS/DEV_PROGRESS/WRITING_PROGRESS/CHANGELOG와 `CODEX_APPLY_V3_6.md`, 엔진 개선/이미지 정책, v3.5 집필 보고서를 읽었다. 원본은 `spec/content-v3.6-story-engine-art/`에 보존하고 기존 기록은 변경 전 커밋으로 확보했다. 이 ZIP은 런타임 패치가 아니라 콘텐츠/자산/지침 패키지다.

## 실제 코드 반영

- `src/ui/illustrations.ts`는 v3.6 매니페스트/정책/명시 규칙을 읽는다. 새 CG는 기존 `child` 사건의 **12세**, **‘미나는 당신에게 나무칼을 쥐여 줬다.’** 문단 뒤에서만 연결한다. 다른 나이/다른 문안/문맥 없는 호출에는 배치하지 않는다.
- 실제 그림을 열어 확인했다. 미나가 마을에서 나무칼을 건네는 모습이다. `mina_festival` 본문에는 나무칼 건네기가 없으므로 이 CG와 연결하지 않는다. 제공된 축제 규칙은 인물 초상 우선/없으면 생략으로 처리하며 새로운 사건을 등록하는 규칙으로 사용하지 않는다.
- 매니페스트의 원본 width로 CSS 상한을 설정했다. PC680×360/모바일480×240 상한과 페이지 높이 제한을 함께 적용해 원본770×575보다 크게 표시하지 않는다. 비율 예약/contain/lazy/async/실패 시 프레임 제거/한 사건 한 장을 유지한다.
- 기존45개 이미지와 경로/바이트를 보호하고 새 WebP1개만 추가했다. 신규63,302바이트(약62KiB), 전체46개626,162바이트. 기존 사건/선택/엔딩/상태/세이브/나이 원본 JSON5개는 v2.6과 동일하다.

## 문안 병합 준비와 실행 미적용 범위

현재 공개 앱의 로더는13사건/7엔딩의 축소판이다. ZIP이 전제하는65개 확장 사건 엔진은 아직 연결되지 않았다. 따라서 `content/events_v2_9.json`에 **65개 병합 준비본**을 만들었으며 이 파일의 존재를 공개 플레이 적용으로 보고하지 않는다. 이번 작업으로 핵심16사건/8엔딩이나 회차 해금을 새로 활성화하지 않는다.

- v3.5: mina_medal, mina_bridge, fake_awaken, birth_archive, orphan_registry, retired_king, princess_coronation, statue, peace_treaty, grandchild_question의10개 본문/30개 결과 변경을 준비본에 반영했다.
- v3.6: birth_tax, village_well, school_map, first_wage, guard_toll, mina_festival의6개 본문은 그대로이며18개 선택 결과 문단을 강화했다.
- 원본의18개 result는 첫 문단만 담고 resultParagraphs에는 추가 작가 서술이 있다. 배열을 그대로 합쳐 result18개와 기존 resultNarrative15개를 동기화했다. 원본 ZIP은 수정하지 않았고 새 서술을 만들지 않았다.
- 65개 ID/195개 선택 ID/설명/조건/효과/나이/우선순위/회차 조건은 v3.4와 같다. JSON 문단 일치와 보호 비교는 통과했지만65개 엔진 도달/해금/연령 진행의 런타임 검증은 미실시다.

파일별 SHA-256/변경 ID/정적 결과는 [감사 JSON](v36-import-audit.json), 집필의 고유 ID/중복 집계 기준은 [WRITING_PROGRESS](../WRITING_PROGRESS.md)를 참조한다. 새 보고서는 집중 재집필9+3+10=22개를 확인한다. 이번6개는 그22개에 모두 포함되므로 원본28/65를 고유 사건 완료율로 적용하지 않았다. 기존 집필3개는 별도 이력으로 보존한다.

## 검증 및 실패 이력

- 관련 단위6개 검사에서 원본의18개 결과 문자열/문단 불일치를 발견했다. 제공된 배열을 기준으로 정확히 해당 필드만 동기화한 뒤6개 모두 통과했다.
- 전체 검사에서 단위114개/PC·모바일102개가 통과했다. 이후 검수 스크립트의 스크롤 전용 캡처 분기 안에 남아 있던 불가능한 page 비교를 TypeScript가 거부했다. 해당 한 줄을 제거하고 타입/콘텐츠/분기/빌드를 다시 확인한다. 검사 비활성화/게임 코드 추측 변경을 하지 않았다.
- ZIP 목록 출력은 Python의 Windows cp949 콘솔 인코딩으로 실패했다. 안전한 경로 검증/압축 해제는 이미 완료됐으며 문서는 PowerShell UTF-8 읽기로 확인했다. 같은 실패한 출력 방식을 반복하지 않았다.

```powershell
npx tsx scripts/verify-illustrations-ui.ts http://127.0.0.1:4175/ --screenshots
npx tsx scripts/verify-illustrations-ui.ts http://127.0.0.1:4175/ --high-dpi --screenshots
```
