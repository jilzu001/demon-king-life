# v3.8 최소 두 선택지 병합

기준일 2026-10-15. 작업 전 기준260857c/공개 게임3da8e19. [지시서](../spec/content-v3.8-min-choices/CODEX_APPLY_V3_8_CHOICES.md)를 읽고 최신 데이터를 우선해 신규 선택만 병합했다. UI 배치·조작 구성은 변경하지 않았다.

5개 사건에7개 추가, 전체16사건/43선택/8엔딩. 선택 가능한 일반 사건의0~1개 예외는 **0개**다. 엔딩8개는 별도 JSON의 결과 유형으로 선택 사건에서 제외한다. 단순 전환 노드는 없다. 준비본65개는 모두3선택으로 정적 검사만 수행했으며 실제 로더/회차 해금 연결은 여전히 미적용이다.

마지막 세 신규 선택은 제공된 서로 다른 결과 서술·고유 플래그를 기록한 뒤 기존 엔딩으로 간다. 별도 엔딩이나 플래그에 반응하는 엔딩 본문을 추가하지 않았다. 원본의 `mixed` 판정과 효과를 그대로 적용한다. 이의 신청은 등록 취소 성공으로 바꾸지 않으며, 급여 요구도 금화 지급으로 바꾸지 않는다.

## 보호·호환성

- [병합 감사 JSON](v3.8/merge-audit.json)에 변경 ID, 플래그, 목적지, 미적용된 ZIP의 오래된 내용과213개 보호 파일 해시를 기록했다. 적용 전 핵심 장은 [원문 백업](../backups/before-v3.8/01_complete.json)에 보존했다.
- 기존36선택 전체 객체·순서, 사건 본문/연대기/나이/진입 효과,8엔딩, 엔진/저장/그림/연결은 유지했다. v3.8의 장 전체 덮어쓰기를 하지 않았다.
- ZIP의 시험은 최신4선택과 달리 기존 attack/refuse/invoice가 없고, confess 문구도 달랐다. 이 변경과 별도 stand_ground/absurd_invoice는 적용하지 않았다. 최신 연대기 요약, 매니페스트와 엔딩 연출도 유지했다.
- 20세 exam은 attack/refuse/invoice/confess 네 선택이며 고백 문구는 정확히 **‘미나에게 사랑한다고 고백한다.’**다.
- 스토리/저장 버전은2.3.0-compact 유지. 기존 원장 재현을 그대로 지원하므로 저장 초기화나 스키마 이관을 추가하지 않았다. 구2.2의 엄격한 검증/백업 이관도 유지한다.
- `assertCompactChoiceMinimum`을 배포 전 검증에 연결해 일반 사건0·1선택을 거부한다. 구 저장 재현용 과거 계약과 보관 원작은 이 새 콘텐츠 규칙으로 거부하지 않는다. 준비본65개도 별도 정적 검사한다.
