# v2 통합 작업본 검토 — 2026-10-14

첨부 ZIP을 `spec/content-v2-handoff/`에 원본 그대로 보관하고, 기존 콘텐츠를 `backups/before-content-v2/`로 백업했습니다. 작업 브랜치는 `integration/content-v2-handoff`입니다. 공개 게임·엔진·세이브는 아직 교체하지 않았습니다.

## 실제 데이터 검사

| 항목 | 현재 v1.1 | ZIP 작업본 | 기존 선택 보존 후보 |
| --- | ---: | ---: | ---: |
| 장면 | 98 | 98 | 98 |
| 선택 | 340 | 293 | 340 |
| 엔진 전수 검사에서 도달한 장면 | 98 | 91 | 98 |
| 엔진 전수 검사에서 도달한 엔딩 | 34 | 25 | 34 |
| 기존 조기 사망 세이브 복원 | 통과 | 실패 | 통과 |

- ZIP은 47개 선택을 삭제했습니다. 남아 있는 선택의 ID·조건·가중치·효과·목적지와 장면 나이·진입 효과·초기 상태는 기존과 같습니다.
- 원본 작업본은 실제 엔진 판정으로 탐색했습니다. `end_blade`, `end_bench_revolution`, `end_fake_pedigree`, `end_auction_lord`, `end_expensive_paper`, `end_pension_king`, `end_market_gardener`, `end_unforced_truce`, `end_collective_reform`에 도달하지 못합니다.
- 기존 선택 47개를 메모리에서만 복원한 후보는 기존과 상태 수·전이 수·종단 경로 수·각 엔딩 경로 수가 모두 같습니다. 공개 파일에는 적용하지 않았습니다.
- 삭제된 `second_attack`을 포함하는 기존 세이브는 ZIP 원본으로 재검증할 때 `선택 결과 원장 오류`가 납니다. 선택 보존 후보에서는 난수·원장·전체 상태가 그대로 복원됩니다.
- 본편 스키마·ID 참조·DAG·가중치·상태·교착 검사는 통과했습니다. 도달 불가능한 장면/엔딩은 실패 사항으로 별도 기록했습니다.
- `presentation.json`의 98개 장면 모두에 `v2Authored`가 있지만, ZIP에 포함된 스키마와 현재 앱 스키마 모두 이 필드를 허용하지 않습니다. 스키마 확장 없이 적용하면 대화 데이터 로딩이 폴백됩니다.
- 98개 장면 모두 본문 끝과 사이드카에 동일 대사가 들어 있습니다. 기존 렌더러에 그대로 적용하면 중복 표시됩니다. 동일 대사를 정확히 한 번만 표시하는 통합 처리가 필요합니다.
- `ending_cinematics.json`의 34개 엔딩 참조는 유효합니다. 동봉 TypeScript 초안은 새로고침 복원, 회상 자동 진행, 획득 날짜/횟수, 기존 도감 이관까지 완성된 구현은 아닙니다.

## 집필 상태

`CONTENT_STATUS_V2.json`은 직접 집필한 새 장면 14개, 추가 집필이 필요한 장면 84개라고 명시합니다. 다른 README에는 8개/18개라는 과거 수치가 남아 있고 `presentation.json`의 `v2Authored: true`는 26개입니다. 서로 불일치하므로 이 값을 근거로 전체 집필 완료를 선언하지 않습니다.

장면 나이와 간격은 기존과 같습니다. 84개 미완성 장면을 Codex가 임의로 늘리거나 요약문을 완성 서사로 포장하지 않습니다.

## 적용 대안

1. 기존 선택·엔진 판정·34개 엔딩을 유지하고 ZIP의 새 문안/대사/결말 연출을 통합합니다. 삭제된 선택은 기존 데이터 그대로 보존합니다. 스키마·중복 대사·기록/엔딩 연출·도감 이관을 단계적으로 구현하고 검증한 뒤 배포합니다.
2. 선택 삭제를 유지하는 v2 작업본은 별도 브랜치의 검토 대상으로만 두고 공개 배포는 보류합니다. 콘텐츠 제작자가 분기·집필 상태를 정리한 ZIP을 제공하면 다시 검증합니다.

초기 사용자 지시에는 기존 기능·34개 엔딩 보호가 있습니다. 첨부 문서의 선택 축소와 충돌하는 부분이므로 적용 방식을 확인한 뒤 진행해야 합니다.
