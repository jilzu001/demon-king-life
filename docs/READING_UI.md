# 연대기 순차 표시와 스킵 — 2026-10-14

이 문서는 최초 순차 표시 적용 기록입니다. 최신 화면의 타이틀·HUD·GPT식 대화창·선택 팝업·연령/감정 초상화는 `CHAT_UI.md`를 참고하세요. 읽기 간격/스킵/저장 보호 원칙은 유지합니다.

사용자의 후속 요청으로 즉시 노출되던 선택지를 읽기 표시 뒤에 공개합니다. 기존 콘텐츠·판정·상태 변경·저장·엔딩은 그대로 유지합니다.

- 처음 시작할 때 성장 연대기를 한 줄씩 보여줍니다. 이후에는 최근 선택의 확정 기록과 새로 방문한 장면의 요약을 순서대로 보여줍니다.
- 연대기 뒤에 제공된 본문 한 단락과 각 화자의 대사를 표시합니다. 대사마다 클릭할 필요 없이 자동으로 이어집니다. 모든 표시와 마지막 읽기 시간이 끝나면 선택지가 열립니다.
- 기본 대기 시간은 표시한 글자 수 × 125ms, 최소 1.4초입니다. 문장이 길어도 임의로 잘라내거나 짧은 최대 대기 시간으로 제한하지 않습니다.
- 내용 클릭 또는 ‘빠르게 표시’는 이후 줄의 간격을 160ms로 줄입니다. 즉시 완료하는 ‘스킵’과 구분합니다. 스킵은 현재 장면에만 적용되며 다음 장면은 다시 천천히 시작합니다.
- 읽기 중에는 선택지를 숨기고 비활성화하며, 직접 이벤트를 발생시켜도 선택 처리 함수가 거부합니다. 조건을 충족하지 못한 선택지는 스킵 후에도 실행되지 않습니다.
- 모바일에서는 새 연대기를 먼저 보여주고 진행 이후에는 최근 3개만 표시합니다. 요약을 두 줄로 잘라내던 표시를 해제했습니다. 전체 기록은 그대로 보존되며 언제든 열람할 수 있습니다.
- 전체 기록/설정 창을 열면 읽기를 멈추고 닫으면 이미 표시한 줄 다음부터 이어갑니다. 스킵·대기·읽기 진행은 저장하지 않으며 새로고침 후 저장된 현재 장면을 다시 표시합니다.
- 타이머는 렌더링·장면 교체 시 취소합니다. 이전 장면의 타이머가 새 선택지를 열지 않습니다. 줄 표시의 희미한 등장 효과는 ‘동작 줄이기’ 환경에서 생략합니다.
- 브라우저의 기본 DOM, `setTimeout`, `hidden`, 네이티브 버튼·dialog를 사용했습니다. 새 런타임 라이브러리나 저장 필드를 추가하지 않았습니다.

## 확인 과정과 해결한 문제

- 최초 패치의 테스트 문맥 일부가 실제 한 줄 코드와 맞지 않아 적용 전에 중단됐습니다. 현재 문맥으로 패치를 다시 작성했으며 부분 수정은 없었습니다.
- 첫 회귀 검사에서 스킵 직후 특정 버튼에 포커스가 있다고 가정한 검사가 실패했습니다. 기존 400ms 잠금 중에는 버튼이 비활성 상태이므로, 새 요구사항에 맞는 선택지 공개 검사로 변경하고 별도 테스트에서 새 연대기의 최초 포커스를 확인합니다.
- 이전 브라우저 검사 종료 전에 별도 Playwright 실행을 시작해 포트 점유와 검사 산출물 충돌이 발생했습니다. 기존 실행이 종료된 것을 확인한 후 단일 실행으로 검증했습니다. 포트 재사용으로 오류를 숨기지 않았습니다.
- 모바일의 실제 더블클릭에서 첫 선택 직후 연대기로 이동하며 두 번째 클릭이 전체 기록 버튼에 닿았습니다. 원장은 한 번만 저장됐지만 기록 창이 열리는 문제였습니다. 기존 400ms 잠금을 메뉴 버튼에도 적용하고 이벤트 처리 시에도 busy를 확인합니다. 스킵은 표시만 변경하므로 계속 사용할 수 있습니다.

## 검증 명령

`npm run check`는 기존 검증에 PC/320px 모바일 순차 표시 검사 10개를 포함합니다. 가상 시계로 정상 읽기 순서·시간 간격·클릭 가속·스킵·새 장면 잠금·메뉴 일시 정지·새 회차/새로고침·타이머 취소·저장 원장 불변을 확인합니다. 기존 분기 검사는 실제 스킵 버튼을 이용해 진행합니다.

최종 로컬 `npm run check` 종료 코드 0: 단위/통합 96개, 브라우저 46개, 타입·콘텐츠·전수 분기·빌드 통과. 루트 빌드의 PC/390px 실제 실행도 아래 검증 명령으로 통과했습니다. 공개 반영은 기존 GitHub Actions 검증/배포 성공 후 동일 명령으로 확인합니다.

실제 빌드와 공개 주소는 다음 명령으로 확인합니다.

```powershell
npx tsx scripts/verify-reading-ui.ts http://127.0.0.1:4175/
npx tsx scripts/verify-reading-ui.ts https://jilzu001.github.io/demon-king-life/
```

PC 1280px/모바일 390px의 순차 표시·클릭 가속·스킵·원장 보호·새 장면·조기 사망 엔딩·새로고침 복원과 페이지 오류를 확인합니다. 읽기 화면 캡처는 `reading-desktop.png`, `reading-mobile.png`입니다. 실제 휴대기기/Safari/Firefox는 검증 범위 밖입니다.
