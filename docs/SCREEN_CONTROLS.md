# 메인 화면·타이틀·글자 밝기 개편

기준일 2026-10-15. 기존 게임 데이터/엔진/저장 버전2.3.0-compact는 유지하며 화면과 조작만 변경했다. 아래 로컬 회귀/실제 빌드 검수는 완료했으며 공개 배포 확인은 별도로 기록한다.

| 요청 | 적용 |
| --- | --- |
| 1. 설정에서 타이틀로 | 설정의 ‘타이틀로 가기’. 회차/원장/도감은 유지하며 읽기 타이머를 멈춘다. 새로고침해도 타이틀에 머물고 이어하기로 재개 |
| 2. 글자 밝기 조절 | 설정의 ‘화면 전체 글자 밝기’.0% 짙은 회색(#707070)~100% 기존 밝기,5% 단위 슬라이더/어둡게·밝게/기본 밝기. 글자·버튼·능력치·연대기·선택지·타이틀/설정에 적용 |
| 3. 타이틀 새로하기 | 기존 이어하기와 별도 ‘새로하기’. 기존 새 회차 생성 함수를 재사용하며 발견한 엔딩 도감은 유지 |
| 4. 상단 전체 기록 | 오른쪽 NPC/배경 초상화는 공개 화면에서 제거. 같은 자리에 전체 기록 버튼을 배치하고 과거 사건 재선택 유지 |
| 5. 나의 인생 삭제 | 메인 제목과 기존 위치의 기록 버튼 삭제. 접근성 이름은 ‘최근 연대기’ |
| 6. 능력치 한 줄 | 2×2칸을 유지하고 각 칸 안에서 ‘나이 0세’, ‘전투력 2’, ‘마력 0’, ‘금화 0’처럼 이름과 값을 나란히 표시. 작은 화면 기본 글자도 확대 |
| 7. 연대기 딱 한 줄 | 메인에는 가장 최근 사건1개만, 나이/요약 한 줄·말줄임. 전문/과거 기록은 상단 전체 기록으로 열람 |
| 8. 타이틀/초상화 꽉 채움 | 타이틀 배경과 상단 주인공 초상화는 cover로 확대/크롭하여 빈 틈 제거. 최신 사용자 요청에 따른 예외이며 본문·주마등·엔딩 일러스트의 원본 크기 상한/contain은 유지 |

글자 밝기는 `demon-king:ui:text-brightness`에 별도 저장한다. 기본값100이며 잘못된 값/읽기 실패는100으로 표시한다. 저장 실패 시 현재 화면에는 적용하고 안내한다. 그림·배경에 밝기 필터를 씌우지 않는다. 기존 글자 크기100~150%와 읽기 방식은 유지한다.

## 검증 상태

- 관련 PC/모바일6개 검사 통과: 타이틀 이동/새로고침/이어하기의 원장 불변, 새로하기의 새 회차/도감 보호, 밝기0/50/100·재로딩·타이틀/기본 복원·잘못된 값 폴백,150% 한 칸/연대기 한 줄·상단 전체 기록·cover,65세 실제 후반 저장의 화면.
- 초기4개 실패는 재로딩 직후 DOM을 기다리지 않은 검수 코드와 ‘돈을 받는다’는 문구에 gold effects가 있을 것이라는 검수 픽스처의 가정 때문이었다. 실제 원문 effects는 없고 gold0이다. DOM 대기를 고쳤고 후반 실제 상태로 검수했다. 금화를 임의 지급하거나 게임 논리를 바꾸지 않았다. 수정 후6개 모두 통과했다.
- npm run check 종료0: 단위120+브라우저114=234개, 타입/스키마/현재319경로·8엔딩/보관 원작34엔딩/프로덕션 빌드 통과. [전체 로그](compact-controls/check.log).
- 실제 빌드 PC1280×900·모바일 세로320×568/360×800/390×844/430×932, 스크롤/페이지·글자150%·확대100%·DPR1/2 각120개, 총240조합 통과. 능력치/연대기 한 줄·상단 기록/본문 모든 글자·그림 크기/화면 넘침·선택/원장 불변 확인. [DPR1](compact-controls/ui-dpr1.log), [DPR2](compact-controls/ui-dpr2.log).

## 변경 범위

`src/app/main.ts`, `src/styles/main.css`: 화면/읽기 조작 연결/표시 환경 설정. `tests/e2e/compact.spec.ts`와 기존 검수 스크립트들은 새 위치·한 줄·NPC 제거에 맞춰 갱신했다. 보관 원작의 상단 UI와 회귀는 유지한다. 스토리/선택 ID·판정 확률·effects·엔딩·저장 스키마·이미지 파일·집필 변경 없음.

이전 [v3.7 이미지 보고서](V3_7_APPLY.md)는 c6bbd96 당시의 기록이다. 인물 정체성 검수와 본문/회상 그림은 유지하되, 이번 요청으로 공개 화면의 오른쪽 NPC 표시가 제거됐다.
