## 해마다 한 문장 일상

- v5 전환 때 기존 v4.5 일상 문장을 제외하며 연간 표시가 함께 빠진 원인을 확인했다. 다른 루트의 구판 서사를 재사용하지 않고 별도 보조 데이터 `src/content/generated/daily-life-v50.json`의88개 한 문장 일상(연령18·루트64·예비 공통6)을 추가했다. 원고47개 사건과32개 결말은 대량 재집필하지 않았다.
- 실제 방문한 두 사건의 사이 연도만1년 단위로 채운다. 유아/어린이/청소년/공통과8개 실제 선택 루트별 풀을 구분한다. 12세 전 미나를 만난 기억, 실제 하지 않은 범죄/성공/혼인/새 능력을 만들지 않는다.
- 회차 seed·나이·이미 선택한 방향의 표시 전용 해시로 고른다. 게임 RNG를 소비하거나 효과/플래그/가짜 방문/선택을 추가하지 않는다. 같은 저장·JSON 복원·재선택·새 기기의 같은 경로에서는 같은 문장이다. 시드가 다른 새 회차에서는 달라진다.
- 본문에서는 자동으로 한 기록씩, 클릭으로 다음 기록, 스킵으로 선택까지 이동한다. 페이지 방식은 한 페이지의 글을 즉시 표시한다. 최근 연대기는 기존대로 한 줄, 전체 기록에서는 실제 지나간 연간 일상도 확인한다. 원본 조건부 연대기80규칙(고유40문안)과 엔딩 회상256규칙(고유43문안)은 실제 조건에 맞을 때 별도 표시한다.
