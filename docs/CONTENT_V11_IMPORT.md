## 전수 검증 보완과 실패 기록

첫 상태 탐색은 불필요한 과거 값 때문에 100,000개 상한을 초과했습니다. 미래 읽기 값과 상수 덮어쓰기를 반영한 키도 상한을 넘었으며, 세 차례의 상한 초과를 완료로 처리하지 않았습니다. 원인 재분석에서 현재 작품의 숫자 변경은 모두 상수 set이고, 금화/신뢰의 조건은 임계값 비교임을 확인했습니다.

검증기만 판정 동등 상태를 병합하도록 보완했습니다. 이후 조건에 읽히는 배열 항목·값, 생사·관계·법적 근거를 보존하고, add가 없는 숫자는 모든 비교 임계값의 아래/동일/위 범위로 구분합니다. add가 있는 필드는 필요한 실제 값을 보존하고 음수 지출·관계 범위·부활 보호를 검사합니다. 실제 GameState·RNG·선택 로직은 수정하지 않습니다. 모든 자격 결과의 양의 가중치를 가능한 결과로 탐색하며 경로 수를 누적합니다. 상한은 100,000개로 유지했고 상한 내 종료했습니다. 수치는 개별 경로를 수십억 번 반복 실행한 결과가 아니라 동등 상태 병합을 이용한 전수 검사입니다.

브라우저 테스트 시작 시 테스트 보조 파일이 엔진 모듈을 직접 가져와 Node ESM의 Ajv 확장자 해석 오류가 났습니다. 브라우저 테스트에는 원본 매니페스트에서 구성한 초기 세이브 fixture만 사용하도록 수정했고 런타임 엔진을 바꾸지 않았습니다. PC 스크롤 테스트의 임의 100px 제한 1건은 실제 결과 영역이 화면 상단 35% 안에서 읽히는 위치인지 확인하도록 고쳤습니다. CSS 파일 교체의 중복 패치 대상 오류도 원인을 확인하고 단일 파일 갱신으로 처리했습니다.
