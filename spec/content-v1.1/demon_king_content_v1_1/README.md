# 《가짜 마왕의 일생》 콘텐츠 v1.1.0

기존 v1.0의 **98개 장면 · 340개 선택지 · 363개 결과 · 34개 엔딩**을 유지한 표현 강화판입니다.

## 보완한 내용
- 선택지 340개 **전부**에 개별 `description` 작성(기존 8개 포함하여 전부 재검토).
- 98개 방문 장면 전부에 연대기 요약 `chronicleSummary` 작성.
- 중요한 장면 29곳에 인물 간 대화 **116줄** 작성.
- 주요 장면 29곳에 확인 가능한 장소 `locationLabel` 작성.
- **새 선택지/분기/엔딩/상태변이 없음.** 원본 캐논과 20세 시작점 그대로.

## 실전 적용 방식

`story.json`, `chapters/*.json`, `characters.json`, `endings.json`은 v1.0과 같은 폴더 구조로 복사합니다.
기존 엔진의 선택지 스키마에 `description`이 이미 존재하므로 바로 읽을 수 있습니다.

새 파일 `presentation.json`은 **표시 전용 사이드카**입니다. 기존 챕터 JSON에 미인식 필드를 덧붙이지 않아 구 버전 스키마 검증을 보호합니다.
새 UI에서는 `node.id`로 찾아 추가 화면 정보를 표시하세요. 코드 적용 예시는 `CODEX_IMPORT.txt`에 있습니다.

- `chronicleSummary`는 **그 장면에 실제 도착했을 때 확인 가능한 사실의 1~2문장 요약**입니다. 모든 요약을 게임 시작 시 표시하면 안 됩니다.
- 첫 장면 `dk20_exam`의 `chronicle` 4개 항목(출생 0세, 6세, 12세, 17세)은 최초 1회만 표시합니다.
- 방문하지 않은 노드의 요약은 절대 출력하지 않습니다.
- 특정 선택의 성공/실패는 기존 `outcome` 판정값과 도착 노드를 기준으로 반영합니다. `chronicleSummary`는 플레이어가 선택한 결과 자체를 미리 확정하지 않습니다.
- `dialogues`는 대사 넘기기 없이 사건 본문 **아래에 한꺼번에** 보여줍니다. `body`도 삭제하지 않습니다.
- `locationLabel`이 없으면 장소를 생략하거나 사건 제목을 대신 사용합니다. 추측해 생성하지 않습니다.
- `description`은 **선택 전에 노출하는 위트 있는 설명**이며 성공 확률이나 결과를 확정하지 않습니다.

## 주의할 이야기 사실
- 주인공의 전투력은 기본 2, 마력 0. 미나 전투력 8,402.
- 이체 기록 199만 7,000금화가 전부 횡령이라는 뜻은 아님.
- 55세 감사 장면에서 허위 납품 **12만 금화**가 입증되지만 전체 횡령은 확인되지 않음.
- 미나·에리시아의 동의 없는 결혼·애정 회복 자동 성공 금지.

## 검증

```sh
python -m pip install jsonschema
python tools/verify_content.py
python tools/verify_v11.py
```

`verify_content.py`: v1.0부터 이어진 구조·상태·시드 기반 30,000회 경로 검증.
`verify_v11.py`: 전 장면 요약/설명 커버리지, 표시 스키마, 참조, 기존 로직 동일성 검사.

상태 공간 전체 전수 검사는 아닙니다. 실제 엔진 구현과 저장·복원 테스트는 코덱스에서 별도 진행해야 합니다.
