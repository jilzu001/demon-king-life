# 가짜 마왕의 일생 — v2.0 집필 중간본 (완성본 아님)

이 ZIP은 완성된 웹소설급 콘텐츠가 아닙니다. 기존 98개 장면의 구조를 바탕으로 선택지 개수를 2~3개로 축소하고, 주요 8개 장면의 대화를 직접 새로 쓴 작업 초안입니다.

**주의:** 선택지 삭제로 도달 가능한 경로·엔딩이 바뀔 수 있습니다. 엔진에 그대로 덮어쓰지 마세요. 기존 v1.1을 백업하고 별도 브랜치에서 검증해야 합니다.

나머지 90개 장면은 아직 기존 요약문 중심입니다. 이것을 완성본으로 포장하거나 34개 엔딩이 모두 유지된다고 주장하지 않습니다.

콘텐츠를 정말 완성하려면 90개 장면의 대사·후폭풍을 개별 집필하고, 선택지 축소 이후 전체 엔딩 도달성과 저장 호환성을 재검증해야 합니다.
