# 코덱스 적용 지시 — 엔딩 순차 연출

게임에 엔딩이 확정된 시점에서 기존 결과 화면을 바로 표시하지 말고 `mountEndingSequence`를 호출한다. `ending_cinematics.json`의 `scenes`에서 `endingId`가 같은 레코드를 찾는다. `ending_ui/ending-sequence.ts`와 CSS를 기존 Vite 프로젝트에 통합한다.

- `run.memories`는 **실제 플레이 로그에서만** 추출한다. 방문하지 않은 사건을 절대 삽입하지 않는다. 최대 8개, 시간순, 중요한 사건을 우선한다.
- 화면은 네 번의 순차적 장면으로 바뀌어야 한다. 단계명/단계 번호/진행바는 UI에 노출하지 않는다.
- 중간 장면에서 마지막 장면으로 진입할 때만 `unlock()`으로 도감에 영구 저장한다. 이전에 해금한 엔딩을 덮어쓰거나 삭제하지 않는다.
- 주인공의 생각은 `innerVoice`로 보여주되, 이후 실제 플레이 플래그에 따른 맞춤형 대사를 추가할 수 있다. 현재 기본 문구는 엔딩별 초안이며 웹소설 수준 최종 교정이 필요하다.
- SVG는 외부 리소스 없는 가벼운 기본 삽화다. 향후 사건별 SVG로 교체 가능하다.
- 재시작과 도감 보기 버튼은 기존 게임 핸들러에 연결한다. 기존 엔진/저장 데이터/엔딩 판정 로직을 변경하지 않는다.
- 테스트: 화면 전환 순서, 플레이 로그 외 사건 노출 금지, 중복 해금, 모바일 화면, 뒤로가기/새로고침 시 상태, 접근성 확인.
