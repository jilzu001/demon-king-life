# 《가짜 마왕의 일생》 콘텐츠·엔진 통합 적용 지시서

## 중요한 사실
이 패키지는 기존 v1.1을 기반으로 집필 중인 **v2 작업본**이다. 모든 장면이 연습 플레이 수준으로 재집필되었다고 간주하지 말 것. `CONTENT_STATUS_V2.json`의 집필 상태를 먼저 읽는다. 미완성 장면을 완료로 표시하지 않는다.

## 0. 보호 절차
현재 프로젝트를 분석하고 별도 브랜치 생성. 기존 저장·불러오기, 게임 진행, 상태/확률 계산, 분기, 도감, GitHub Pages 배포 기능을 보존. 파일 덮어쓰기 전에 기존 파일 백업 및 JSON ID 참조 검증. 자동 변경은 작은 단위로 수행하고 각 단계 테스트.

## 1. 콘텐츠 원본
`story.json`이 시작 노드와 초기 상태를 정의한다. `chapters/*.json`의 `nodes`가 정식 사건·선택·결과·효과 데이터다. `presentation.json`의 `nodes[id]`는 대화·연대기·선택 설명을 보강한다. 같은 ID를 기준으로 결합하고, 없는 항목은 원래 본문으로 폴백. `ending_cinematics.json`은 결말 연출 데이터다. **표시용 대사가 원래 사건의 사실과 충돌하면 원래 사건 및 조건을 기준으로 수정**한다.

## 2. 엔진 타입 확장
기존 타입은 유지하면서 선택적 `dialogues`, `chronicleSummary`, `memoryArtKey`, `memoryCaption`, `memoryPriority`, `reflectionVariants`를 지원한다. 대사는 `{speaker,text,when?}` 구조, `when`은 기존 조건 평가기만 사용. JSON으로 JS 코드를 실행하지 말 것. 사건/선택/결과/엔딩 ID를 무단 변경하지 말 것.

## 3. 진행 UX
한 사건 안에서 도입→갈등→대사→선택을 충분히 보여준다. 대사 한 줄마다 '다음' 버튼을 강제하지 않는다. 선택은 통상 2개, 필요할 때만 세 번째 황당한 선택을 허용하되 데이터에 있는 유효 선택을 임의로 삭제하지 않는다. 선택 후 `outcomes`의 가중치·조건을 기존 엔진 방식으로 처리하고, `result` 서술을 먼저 보여준 다음 `to`로 이동. 사건이 짧은 연대기 항목이면 별도 선택 없이 연결할 수 있는 타입을 새로 지원하되 무한루프 검사.

## 4. 실제 플레이 기록
이벤트마다 `nodeId`, `age`, `choiceId`, `outcomeId`, `resultText`, `chronicleSummary`, `memoryArtKey`, `memoryCaption`, `memoryPriority`, `timestamp/order`를 저장. 기록은 **확정된 결과 이후** 생성. 이전에 보지 않은 노드를 기록하지 말 것. saveVersion을 올리고 기존 세이브 마이그레이션; 원본 세이브 백업; 재시작 후에도 기록 유지.

## 5. 결말 시퀀스
결말에 진입하면 일반 HUD 숨김. **동시에 나열하지 말고 별도의 전체 화면 네 장면으로 순차 전환**:
A. 결말별 마지막 서사 (`closingScene`).
B. 실제 기록에서 중요한 사건 4~8개를 골라 각기 하나씩 간단한 SVG/CSS 일러스트와 문장으로 회상. 반드시 실제 경험한 사건만, 순서/인과관계 유지. 기록이 4개 미만이면 실제 기록만 보여주고 허구를 보태지 않는다.
C. 결말·관계·선택에 맞는 주인공의 마지막 생각 (`innerVoice` + 조건부 변형). 불일치 시 안전한 결말 기본 문구.
D. 결말 이름·상징 그림을 보여주고 엔딩 도감에 등록.
**게임 화면에 '마지막 순간', '주마등', '독백', '엔딩카드'라는 용어, 단계 번호, 1/4 같은 진행률을 절대 표시하지 말 것.** 각 화면은 독립적으로 전환하고 이전 화면을 아래로 누적하지 않는다. 짧은 페이드; 긴 문장을 강제 타이머로 넘기지 않음. 회상은 자동 넘김+터치 스킵; reduced-motion 지원. 연출 중 새로고침 복원.

## 6. 도감
도감은 게임별 세이브와 별도 로컬 영구 저장. `endingId`를 키로 최초 획득 날짜/획득 횟수 관리. 중복 등록 금지. 미발견 항목은 스포일러 없는 실루엣. 새 게임 시작 시 도감 보존. 기존 도감 마이그레이션.

## 7. 이미지
SVG/CSS 기반 기본 자산. 스토리 JSON에 거대한 SVG를 넣지 않고 `artKey`로 에셋 레지스트리 참조. 미등록 키는 기본 실루엣 폴백. 외부 API나 대형 동영상 의존 금지. 나중에 WebP 등 교체 가능.

## 8. 반드시 검사
- 모든 `to.node.id` 및 `to.ending.id` 참조 유효성
- 조건부 선택이 모두 막혀 교착되는 경로
- 동일 결과 중복 실행/세이브 중복 기록
- 사망 후 생존 인물 대사 등 설정 충돌
- 가중치 분기 재현 가능성, 엔딩 도달성
- 20개 이상 경로에서 실제 읽히는 텍스트를 순서대로 덤프해 빈 대화·반복·앞뒤 모순 점검
- 새로고침/구형 세이브/모바일/정적 빌드 테스트

## 9. 작업 범위 분리 및 보고
엔진 통합 성공과 전체 콘텐츠 집필 완료를 혼동하지 말 것. 콘텐츠는 제공된 텍스트를 사용하며 Codex가 임의로 요약문을 늘려 '완성' 처리하지 않는다. 아직 집필되지 않은 장면은 미완성으로 명시한다. 보고서에 수정 파일, 스키마, 검증 성공/실패, 미완료 장면 수를 기록한다.
