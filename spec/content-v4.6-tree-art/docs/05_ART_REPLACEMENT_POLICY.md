# 전체 일러스트·초상화 교체 규칙

## 최종 그림체 기준: 실제 사용자가 승인한 출생신고 장면

`assets/style_reference/APPROVED_birth_reference.webp` (고해상 원화의 WebP 압축본)과 `APPROVED_user_crop.webp` (사용자 인증 화면 크롭)이 **유일한 승인된 스타일 앵커**다. 이 기준을 무시하고 최근 생성한 ‘엄마=미나’, ‘아빠=성인 주인공’ 그림을 채택하지 않는다.

### 정체성 고정

- 0세 장면: 부모는 갈색 머리 서민 남녀, 주인공은 까만 머리 아기, 마왕 등록을 읽는 남색 행정복 서기관. **은발 미나 절대 없음 / 붉은 망토의 성인 주인공 절대 없음 / 군중·기사단 추가 금지.**
- 미나: 성인일 때 은빛 **긴** 머리, 푸른 눈. 붉은 단발 레온과 구분. 관계는 각 플레이 이력에 따라 상호 동의 등 조건 확인.
- 성인 주인공: 검은/짙은 갈색 헝클어진 머리. 0세 장면에서는 아기 모습만. 나이별 초상화는 생애 단계에 맞춰 별도 원화.
- 국왕·왕녀·감사관·부모/서기관은 각각 별도 얼굴·역할과 해당 장면 출연 조건을 둔다.

### 교체 범위 및 우선순위

1. 기존 `public/art/portraits` 초상화 실제 파일/키/표정/나이 단계 전수, `src/ui/portraits.ts`와 `src/ui/visual-identity.ts`의 이미지 연결 동기화.
2. `public/assets/illustrations/characters`, `event_cg`, `event_cg_v4_5`, `events` 전수. 잘라 붙인 듯한 이벤트 CG 및 유관하지 않은 초상화를 조합한 CG를 독립 원화로 교체.
3. `ending_v4_3` + `assets/ending_art_manifest_v4_4.json`의 20 엔딩. 과거 8개 엔딩이 기존 사건 이미지를 재사용한 것도 새 전용 이미지로 교체하되 도감 잠금 정책 보존.
4. 주마등 flashback은 실제 방문·선택과 일치하는 장면 원화로만. 단순 배경·아이콘으로 대체하지 않기.
5. backgrounds는 심각한 화풍 불일치나 맥락 충돌 시 재작업; 작은 UI 아이콘은 이번 **그림체 교체 대상 아님** (기존 UI 전면 리디자인 취소).

### 실무 적용

- ZIP의 `data/legacy_asset_inventory_v45.csv`는 이전 v4.5 누적 아카이브에 포함된 파일 목록으로, **현재 GitHub 전수 목록 아님**. 코덱스는 라이브 저장소의 모든 WebP를 직접 나열해 통합 목록을 다시 만든다.
- 각 그림의 `assetId, nodeId, age, speakerId, choiceId, outcomeId, flags, target public path, size, preview, approval status`를 엑셀/CSV로 관리.
- **이미지는 제작/검수/용량 확인을 마친 후에만 교체**. 미제작 파일을 우선 경로로 지정하면 안 된다. 이미지 생성 도구가 코덱스에 없다면 본 ZIP의 프롬프트를 사용자에게 넘기고 상태 `미제작`으로 기록.
- 교체 시 기존 경로 유지가 가능하면 같은 파일명으로 원자적 교체. 교체 전 git에서 원본 SHA를 기록하고 복원 가능하게 한다. manifest 우회/새 이미지 섞여 보이는 현상 방지.
- 원본 PNG/JPEG와 게임용 WebP를 분리. 원화 PNG를 Pages에서 로딩하지 않는다. WebP는 이벤트 800~1100px/대략 40~120KB, 초상화 480~640px/15~45KB, 엔딩 800~1100px/50~120KB 목표(절대 조건 아님). 품질을 희생하는 과압축 금지.
- 검증: 인물·나이·관계·선택·장면 합치, 변형·손가락·잘림·합성 흔적, 이미지 크기와 alt, MIME/404, Tistory iframe GitHub Pages base 경로.
- **승인 출생신고 원화는 이미 적합하다. 더 어지러운 그림으로 덮어쓰지 마라.** 스타일 기준으로 유지하고 필요한 경우 동일 원화의 최적화만 실행한다.

### 정직한 완료 보고

본 ZIP은 그림 **전면 교체 완료본이 아니다**. 사용자 승인 그림 1장 3종 크기 압축과 검증된 정사 프롬프트/교체 체크리스트/트리 생성 코드를 제공한다. 새 초상화·20 엔딩 및 나머지 새 CG는 이미지 생성/인물 검수 이후 실제 교체해야 한다. 완료 수치는 '실제 변경되어 게임에서 로드되는 파일'만 집계한다.
