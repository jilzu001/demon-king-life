# 캐릭터별 저용량 초상화 제작 프롬프트 (확정 출생신고 기준 화풍)

## 모든 초상화 공통

사용자가 승인한 출생신고 장면과 동일한 따뜻한 자연광·은은한 수채/페인터리 셀셰이딩의 고급 판타지 애니 일러스트. 선명한 인물 얼굴, 차분하고 촘촘한 선화, 코코아색·크림색·짙은 청금색 소품, 적당한 깊이감의 중세 실내. 하나의 장면을 처음부터 통째로 그린 구성. 종횡비 4:3 또는 3:2의 완성형 그림. 글자·대사풍선·UI·모자이크·캐릭터 시트·콜라주 없음. 등장 인물은 해당 사건의 실제 등장인물만. 과밀 군중 금지.

오류 방지: 0세 장면에 성인 주인공 또는 은발 미나 출연 금지; 레온의 붉은 머리를 미나로 치환 금지; 다른 사건 스틸 컷 붙여넣기 금지; 프레임 가장자리에서 인물 얼굴 임의 절단 금지; 선택하지 않은 분기/획득하지 않은 관계를 그리지 말 것.

- 완성형 상반신 인물 단독 초상화. 단순히 이벤트 CG에서 얼굴을 잘라내지 않는다.
- 512x640 또는 480x640, 무텍스트, 배경은 해당 인물에게 어울리는 매우 흐린 단일 장소. WebP 60~80% 품질 목표 15~45KB(화질 확인 후 조정).
- 실제 repo의 `portraitCharacters / portraitStages / portraitEmotions` 상태와 `public/art/portraits` 파일명을 먼저 전수 조사한다. 0세 주인공 성인 초상화를 사용하지 않는다.
- 어린/성인/중년/노년 변화는 각 사건 실제 나이와 경과 연도에 일치시킨다. 감정만 바뀔 때 얼굴·머리색·복장은 고정한다.

## father

**이미지 생성 프롬프트:** 사용자가 승인한 출생신고 장면과 동일한 따뜻한 자연광·은은한 수채/페인터리 셀셰이딩의 고급 판타지 애니 일러스트. 선명한 인물 얼굴, 차분하고 촘촘한 선화, 코코아색·크림색·짙은 청금색 소품, 적당한 깊이감의 중세 실내. 하나의 장면을 처음부터 통째로 그린 구성. 종횡비 4:3 또는 3:2의 완성형 그림. 글자·대사풍선·UI·모자이크·캐릭터 시트·콜라주 없음. 등장 인물은 해당 사건의 실제 등장인물만. 과밀 군중 금지. 주인공 아버지: 0세 출생신고 기준 어두운 갈색의 짧고 부스스한 머리, 크림색 셔츠와 낡은 갈색 조끼, 평범한 가난한 청년 아버지. 성인 주인공의 검은 로브/빨간 망토 금지. 카메라는 가슴 위 반신 정면 3/4, 감정은 neutral 기준. 필수 표정 변형은 joy, sad, angry, tired, confused, neutral을 같은 얼굴로 독립 제작. 오류 방지: 0세 장면에 성인 주인공 또는 은발 미나 출연 금지; 레온의 붉은 머리를 미나로 치환 금지; 다른 사건 스틸 컷 붙여넣기 금지; 프레임 가장자리에서 인물 얼굴 임의 절단 금지; 선택하지 않은 분기/획득하지 않은 관계를 그리지 말 것.
