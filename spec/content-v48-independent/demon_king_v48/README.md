# 《가짜 마왕의 일생》 v4.8 독립 루트 재구성 팩

이 ZIP은 **여기서 집필한 신규 스토리 데이터** 및 Codex용 안전한 적용 지침입니다. **GitHub에 아직 적용하지 않았고, 일러스트 파일도 생성하지 않았습니다.**

## 구성

- `04_v48_independent_life_routes.json`: 실제 대사·선택·후속 결과를 쓴 **신규 28개 사건** (4개 진입 사건 + 8개 루트 × 3개 사건), **선택지 76개 / 결과 76개**.
- `routing_patch.json`: 기존 20세 시험장의 **기존 4개 선택지와 outcome ID를 그대로 유지**하면서 각 신규 진입 사건으로 향하는 목적지 변경 명세. 이전 사건(감옥/진정서/출연료/고백)도 각 진입 사건에서 선택해 진행 가능.
- `route_matrix.json`: 8개 독립 하위 루트의 사건·엔딩 연결 증빙.
- `illustration_prompts.json`: **신규 사건용 20개 그림 제작 프롬프트**, 기존 승인된 출생신고 그림체 및 캐릭터 불변 기준, WebP 저용량 목표.
- `CODEX_PROMPT.md`: 적용/보호/검증 작업 지시.
- `validation_report.json`: 패키지 자체 구조 검사 내용.

## 서사 설계

20세 용사 시험이 **전투·도주 / 법·개혁 / 돈·권력 / 미나·관계**의 네 삶으로 갈라진다. 각 축에는 서사가 다른 두 개의 독립 하위 경로가 있고, 사건 21세→중년→후반을 거쳐 개별 엔딩을 고른다. **8개 하위 경로는 중간에 공통 사건으로 다시 합쳐지지 않는다.** 끝에 도달하는 기존 엔딩은 일부 공유될 수 있다.

기존 스토리·루트·엔딩은 제거하지 않는다. 새 진입 사건에는 기존 진행을 이어가는 선택이 있다. 이미 저장된 세이브는 실제 노드/버전 호환성을 검증하며 변경하거나 리셋하지 않는다.

## 적용의 한계 및 검증 단계

- 현재 로컬 ZIP은 GitHub 리포지토리의 정확한 최신 커밋을 포함하지 않는다. Codex는 **적용 시점의 로컬 소스와 미커밋 작업을 우선** 확인해야 한다.
- 선택이 같은 루트의 다음 사건으로 합류해도 선택에 따라 최종 결말 선택 가능성이 달라지며, 각 하위 루트는 별도 중년·말년·엔딩 동선을 갖는다. 완전 이진나무 형태의 모든 선택별 독립 엔딩이 아님.
- 새 엔딩을 만들지 않고 기존 20개의 엔딩 자산을 유지한다. 원본 엔딩들의 결말 본문과 신규 루트가 충돌하는 경우, 기존 엔딩을 무단 개작하지 말고 해당 진입만 보류하고 사용자에게 보고한다.
- `CODEX_PROMPT.md`에는 전체 분기 트리 표시, 색상 강조 유지, 스토리 후속 회수, 이미지 제작·압축, 테스트 요구가 포함된다.
