# 가짜 마왕의 일생 — 원작 플레이 기능 완전 제거 (v2.8)

## 목적
현재 운영 중인 **새 엔진만** 유저에게 제공한다. 구형/원작 게임은 오직 개발 참고용으로 보존한다. 원작 실행·복원·이어하기·전환 경로를 앱에서 완전히 제거한다. 이 작업은 UI 문구만 숨기는 것이 아니라 라우트, 이벤트 핸들러, 설정 상태, 임포트, 구형 런타임 분기까지 정리하는 것이다.

## 우선 조사
1. 저장소에서 다음 문자열과 관련 키워드 검색: `원작`, `원작 플레이`, `기존 저장 이어가기`, `업데이트 전 회차`, `축소 완결판 전용 저장`, `legacy`, `original`, `classic`, `oldEngine`, `playOriginal`, `resumeOriginal`, `preUpdate`.
2. 화면 사진의 '저장 관리 · 엔딩 도감' 모달에 표시된 `원작 플레이 · 기존 저장 이어가기` 버튼과 `업데이트 전 회차 JSON 내보내기` 버튼을 우선 제거한다.
3. 원작 플레이 진입점(타이틀, 설정, 메뉴, URL/라우트, 딥링크, 키보드 단축키, 개발자 메뉴), 해당 상태 분기, 이벤트 리스너, 구형 엔진 마운트 코드를 찾아 제거한다.
4. 실제 소스에 있는 명칭·키를 기준으로 작업한다. 이 문서의 예시 변수명을 존재하는 코드로 가정하지 않는다.

## 사용자 화면 — 유지할 것
- 새 엔진의 현재 회차 자동 저장/이어하기, 새 회차 시작, 회차 JSON 내보내기/가져오기, 엔딩 도감
- 글자 크기 설정, 대사 문단 사이 빈줄, 한 줄 연대기 및 전체 기록
- '타이틀로 돌아가기' 추가: 현재 회차 안전하게 저장 → 타이틀 표시. 새 회차 시작과 혼동하지 않도록 별도 버튼으로 제공. 진행 중이면 확인창 사용 가능.
- 원작 관련 표현 없는 '저장 관리 · 엔딩 도감'으로 정리

## 원작 자료 보존 범위
- 원작 스토리/규칙/기존 명세 등 **참고 자료**는 `docs/reference/original/` 같은 비배포 개발 문서 경로로 이동하거나 유지한다.
- 이 폴더의 자료를 빌드의 앱 런타임에 import하지 않는다. GitHub Pages의 공개 정적 자산 경로에 원작 플레이 가능한 HTML/JS 번들을 배포하지 않는다.
- 이전 사용자 저장 데이터는 **삭제하지 않는다**. 특히 localStorage/IndexedDB 전체 초기화, 저장 키 일괄 삭제, 도감 초기화 금지. 원작 저장을 새 엔진이 인식하지 못하더라도 조용히 보존한다. 데이터 마이그레이션은 검증된 별도 절차가 있을 때만 수행한다.
- '원작 복원' 버튼을 남기지 않는다. 개발 참고 자료와 사용자가 접근하는 게임 기능은 분리한다.

## 필수 확인
1. 타이틀/설정/저장 관리/엔딩 도감에 원작 플레이 및 구형 저장 버튼·문구가 없다.
2. 검색 가능한 사용자 경로/라우트로 원작 엔진이 실행되지 않는다.
3. 타이틀로 돌아갔다가 새 엔진에서 이어하기 가능하다.
4. 새 회차 시작 후 기존 엔딩 도감이 유지된다.
5. 회차 JSON 내보내기/가져오기, 글자 크기, 모바일 UI가 정상 작동한다.
6. 저장소 전체에서 원작 관련 코드는 참고 자료만 남았는지 확인한다. 예외가 있으면 파일명과 이유를 보고한다.
7. 빌드 및 기존 테스트를 통과하고, 제거한 기능/보존한 데이터/실행한 테스트를 요약한다.

## 작업 보호
현재 v2.7의 고백 분기 및 스토리 콘텐츠, 8개 엔딩, 모바일 문단 간격과 연대기 한 줄 요약을 변경하지 않는다. 실제 엔진 소스가 첨부되지 않았으므로 이 문서는 **코덱스가 저장소에서 직접 적용할 수정 명세**이며 적용 완료를 의미하지 않는다.
