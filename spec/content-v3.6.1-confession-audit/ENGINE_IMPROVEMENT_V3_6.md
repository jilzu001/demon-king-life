# 엔진 개선 요청 v3.6

## 반드시 지킬 규칙
1. 일러스트는 의무 아님. 관련성이 확실한 첫 등장/주요 사건에만 표시.
2. 인물 중심 대화는 배경보다 인물 초상/해당 행동 CG를 우선. **이미지 이름만으로 잘못된 사건에 CG를 쓰지 말 것.**
3. 원본 해상도보다 크게 표시 금지. CSS: `img { max-width: min(100%, var(--asset-natural-width)); height: auto; object-fit: contain; }`. manifest width/height로 상한 설정.
4. 이미지 없는 사건은 자연스럽게 텍스트만 표시. 화면 높이 빈칸 남기지 말 것.
5. 문단별 전환은 사건별 명시적 앵커가 있을 때만, 기본 한 사건 최대 1장. 이미지로 대사 카드 중복 금지.
6. 새 일러스트 제작 시 광원 단순화, 배경 디테일 축소, 선명한 캐릭터 실루엣, WebP q75~85. 단순 리사이즈는 디테일 복구가 아님.
7. 모바일/PC 이미지 자연 크기 검증, 브라우저에서 확대율 100% 및 고DPI 점검.
8. 실제 프로젝트 코드 확인 전 완료 표시 금지. 테스트 및 미검증 항목 별도 기록.
9. 선택 ID, 이벤트 조건/effects, 저장 데이터/엔딩/해금 호환성 유지.

새 이미지 `mina_wooden_sword.webp`는 미나가 나무칼을 건네는 장면의 **시각적 예시 자산**이다. 이미지가 필요한 정확한 사건 ID/연령과 일치할 때만 연결하라. 해당 장면에 정확한 이벤트 ID를 찾지 못하면 자동 연결하지 말고 보류하라.
