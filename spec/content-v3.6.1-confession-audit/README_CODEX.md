# 《가짜 마왕의 일생》 축소 완결판 — 콘텐츠 v2.2

**범위:** 13개 직접 집필 사건, 24개 선택지, 3개 엔딩. 출생→용사 시험→왕실 장부→법적 분쟁→세 갈래의 삶까지 시작과 끝이 있는 소형 완결판입니다. 기존 98장면/34엔딩의 대규모 초안과 달리, 분량을 줄이고 모든 본문을 수작업으로 작성했습니다.

**중요:** 13개 장면이 모두 긴 것은 아닙니다. 일부 선택은 서로 다른 사건을 거쳐 같은 핵심 장면으로 합류하며, 분기 합류 후 모든 과거 플래그를 대사에 반영하지는 못했습니다. 원래 연습 플레이의 자유로운 상호작용을 완전히 재현했다고 주장하지 않습니다.

## 코덱스 적용

1. 기존 콘텐츠와 저장 데이터를 백업하고 별도 브랜치에서 작업합니다.
2. `story.json`, `characters.json`, `endings.json`, `chapters/01_complete.json`을 콘텐츠 폴더에 배치합니다. 이 파일들은 기존 schemaVersion 1 구조를 따릅니다.
3. `ending_cinematics.json`은 **확장 스키마**입니다. 기존 엔진이 자동으로 읽는다고 가정하지 말고 엔딩 연출 로더를 연결하세요.
4. `outcomes[].narrative`는 선택 직후 출력할 후속 서술입니다. 기존 엔진이 이를 지원하지 않으면 렌더러를 추가하세요.
5. 각 엔딩의 실제 경험 사건만 회상하고, 화면은 순차 전환합니다. '마지막 순간/주마등/독백/엔딩카드' 같은 단계 이름을 사용자에게 표시하지 마세요.
6. `story.json`의 초기 상태는 기존 프로젝트와 호환되도록 유지했습니다. 시작 장면은 출생(0세)이고 초기 상태 age는 20이므로 **장면 진입 시 node.age로 현재 나이를 동기화하도록 엔진을 수정**해야 합니다.
7. 저장 데이터 마이그레이션 없이 기존 98장면 플레이 중인 저장을 이 축소판에 로드하면 노드 ID가 사라져 오류가 납니다. **기존 세이브 자동 적용 금지**, 새 콘텐츠 전용 세이브 슬롯 또는 버전 분리 필수.

## 검증

- 모든 장면 도달 가능, 모든 엔딩 도달 가능, 존재하지 않는 참조 0개
- 선택 결과 24개 모두 목적지 존재
- 실제 UI 실행, 기존 엔진의 타입 검사, 저장 호환성, 모든 분기별 문학적 완성도는 별도 검증 필요


## v2.3 조기 종료 분기 추가

기존 3개 엔딩에 위험한 선택으로 진입하는 조기 종료 4개를 추가했습니다. 감옥 탈옥, 민원실 방화, 국왕 협박, 감사 장부 절도입니다. 각 사건의 선택지는 최대 3개이며, 실패도 즉시 한 줄로 끝내지 않고 후일담과 결말 연출을 거칩니다. 기존 세이브 버전 분리와 엔딩 연출 로더 연결은 여전히 필요합니다.
