# Codex 적용 지침 — v2.7

기존 프로젝트를 삭제하거나 초기화하지 말고 별도 브랜치에서 이 콘텐츠를 교체한다. 기존 저장/엔딩 갤러리 마이그레이션을 유지한다.

1. `chapters/01_complete.json`, `endings.json`, `story.json`을 기준으로 콘텐츠를 갱신한다.
2. 용사 시험 `exam`은 이제 세 선택(고백/거부/황당한 출연료 요구)으로 구성된다. 고백은 `confession`으로 이동하며 진심 고백/철회/시험관에게도 고백하는 황당 선택으로 갈라진다. 다른 기존 경로는 최대한 유지한다.
3. **대사 중복 금지:** `body`에 이미 있는 대사를 `presentation.dialogues` 또는 별도 인물 카드로 다시 표시하지 않는다. 본문 단일 소스를 사용한다.
4. **문단 빈줄:** JSON `body`의 `\n\n`을 문단 경계로 파싱하고 각 문단을 별도의 `<p>`로 렌더링한다. 문단 사이 `margin-block: 0 1.1em`, 본문 `line-height:1.75`. `white-space:pre-line` 하나만으로 처리하지 않는다.
5. 연대기는 본문을 잘라 쓰지 말고 `chronicleSummary`만 사용한다. 화면에 `나이 + 한 문장`만 한 줄로 보여주고 넘치는 부분은 말줄임 처리한다. 모바일은 연대기 최대 3줄 노출 후 전체 기록 버튼으로 접근. 확보된 공간은 본문에 배정한다.
6. 엔딩 추가 `ending_love_scandal`의 등록 및 엔딩 연출을 기존 4단계 구조에 맞게 연결한다. 엔딩별 실제 방문 이벤트만 회상에 사용한다.
7. `story.json`의 초기 상태, 통계, 이전 저장 데이터와 충돌하지 않는지 테스트한다. 새로운 노드 ID로 이동 가능한지, 뒤로가기/재시작/자동저장/모바일 레이아웃을 확인한다.
8. `CODEX_TIMELINE_LAYOUT_V2_6.md`와 `CODEX_PARAGRAPH_FIX_V2_5.md`의 기존 지침도 유지한다.

주의: 이 파일은 **고백 분기 복원 및 주요 새 장면의 개별 집필판**이다. 모든 13개 기존 장면을 전면 웹소설급으로 재집필했다고 주장하지 않는다.
