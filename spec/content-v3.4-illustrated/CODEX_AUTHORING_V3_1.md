# v3.1 집필 강화 적용 지침

- 기존 v3.0을 덮어쓰는 콘텐츠 업데이트. `content/events_v2_9.json`을 읽고 조건부 사건 엔진에 반영.
- `authoredRevision: 3.1`인 9개 사건은 본문을 전면 재집필했으며 선택별 `resultNarrative`를 우선 출력. 기존 `result`와 같은 내용이므로 **둘 다 출력하지 말 것**.
- 본문은 `\n\n` 단위 독립 문단으로 렌더링. 별도 대사 카드 중복 금지.
- 기존 원작 플레이 기능 제거 지침 유지. 타이틀 복귀, 새 엔진 저장, 한 줄 연대기 유지.
- `resultNarrative`가 없는 사건은 기존 `result`만 출력.
- 선택 결과는 단순 토스트가 아니라 본문과 동일한 문단 간격의 이야기로 표시한 후 다음 사건으로 이동.
- 원본 JSON을 임의로 요약하거나 대사를 자동 합성하지 말 것.
- 이 버전은 **9개 사건 집중 집필본**이며 나머지 56개 사건은 기존 v3.0 초판 그대로이다. 전체 65개 웹소설급 완성이라고 주장하지 말 것.
