# v3.2 콘텐츠 적용

1. `content/events_v2_9.json`의 65개 확장 사건을 기존 하이브리드 사건 엔진에 등록한다. 파일 이름은 호환성 때문에 유지했다.
2. `body`와 `choices[].result`의 `\n\n`은 문단 경계이다. `bodyParagraphs`, `resultParagraphs`도 같은 내용으로 제공한다. 본문에 이미 들어간 대사를 별도 대사 카드로 중복 렌더링하지 않는다.
3. 기존 핵심 스토리 `chapters/01_complete.json`의 선택지·엔딩·저장 데이터를 보호한다. 조건부 사건은 메인 플롯을 덮어쓰지 않고 자연스럽게 삽입한다.
4. 1회차 후 해금, 연령 범위, 관계·플래그 조건, oncePerRun을 적용한다. 플래그 변경은 저장·불러오기 후에도 일관되어야 한다.
5. 원작 플레이 실행 경로는 제거한 상태로 유지하고 개발 참고 자료만 보존한다. 설정의 타이틀 복귀 기능을 유지한다.
6. 모든 사건이 적어도 한 경로에서 등장할 수 있는지, 동일 사건 중복 등장 방지, 모든 선택의 결과 문단 표시, 1회차·2회차를 테스트한다.

**편집 범위**: 신규 53개 단편 초안에 장면별 개별 대화와 사건의 감정적 맥락을 추가했다. 9개 기집필 장면과 3개 해금 사건은 유지했다. 선택 결과는 각 사건의 기존 고유 결과를 보존했으며, 53개 사건의 세 갈래 모두에 공통적인 여운 문장을 선택 성격별로 추가했다. 이 결과는 65개의 완전히 독립된 장편 분기를 의미하지 않는다.
