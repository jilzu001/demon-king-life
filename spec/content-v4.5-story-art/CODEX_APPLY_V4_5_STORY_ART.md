# 코덱스 적용 지침 — 《가짜 마왕의 일생》 v4.5 (누적)

## 적용 순서
1. 현재 **실제 게임 저장소**의 코어 노드/연령 진행/도감/엔딩 구현을 먼저 읽고 백업, 테스트 스냅샷 확보.
2. v4.4 누적본의 스토리·엔딩·도감·일러스트를 보존하면서 v4.5에서 수정된 파일만 병합; 파일 전체 무조건 덮어쓰기 금지.
3. `chapters/01_complete.json`: 코어 본문 4개와 결과 4개를 기존 ID, `to`, 효과 플래그 그대로 적용. 20세 `confess`를 포함한 4개 선택지를 보존.
4. `content/events_v2_9.json`: 본문 4개와 결과문 12개 수정, `birth_tax` 연령 6세로 고정. 사용자가 다른 나이에 6세 문장을 읽지 않도록.
5. `content/annual_life_records_v4_2.json`: 연령 10곳 × 후보 5개 = 50개 문장 새 집필 반영. 나이별 5개 중 매회 1개만 표시; 중요 사건이 있었던 해에는 표시하지 않기. 매년 선택지를 만들지 않기.
6. `content/ANNUAL_DATA_MIGRATION_V4_5.md`를 필독. 삭제된 v4.1 매년 선택지 JSON과 과거 플래그 콜백은 **재도입 금지**. 기존 저장 데이터의 잔여 플래그는 읽을 수 있어야 하나, 없는 선택지의 후폭풍은 무시.
7. `content/conditional_story_echoes_v4_5.json`: 실제 보유한 코어 플래그+노드 방문 기록 모두 검사해서 회상 문장을 해당 코어 사건 끝에 삽입. 이미 방문하지 않은 일을 회상하지 않게. 한 사건 최대 1개 (우선순위는 순서 또는 현재 기능과 자연스럽게 병합).
8. `assets/scene_art_manifest_v4_5.json`에 따라 그림 3개 연결. 이 파일은 **연결 지침**이지 엔진에 적용된 코드가 아님. 21세 왕궁 CG는 `invoice`의 `out_bring_mina`를 실제로 골랐을 때만 표시. 미나가 없는 경로/사망/관계가 끊긴 경로에 임의 삽입 금지.
9. 주마등은 방문한 사건/선택만 기반으로 4~8개 사용. 같은 일러스트가 계속 반복되지 않게 하고, 옛 SVG 벡터를 렌더링하지 말 것. 엔딩 도감의 20개 이미지 매핑과 잠금 처리 보호.
10. 실제 GitHub Pages·티스토리 경로에서 이미지 HTTP 200, 캐시·base path, 브라우저 PC/모바일 표시 확인. 이미지 가로 세로비 유지, 이미지 없는 경우 텍스트만 출력.

## 꼭 검증할 경로
- `birth → child → exam`: 각 나이를 1년 단위로 진행. 20세 선택지 네 개(공격·항의·출연료·고백) 모두 표출.
- `exam > absurd_invoice → invoice > bring_mina`: 미나 왕궁 CG가 결과에 한 번만 출력됨. `accept_invite`는 다른 연출.
- `exam > confess → confession > confess_sincere → confession_afterm`: 21세 미나가 시험 포기; 고백으로 자동 결혼 없음.
- `exam > stand_ground → petition`: 21세 민원실 문장 바뀐 내용 확인.
- `audit > public_audit → hearing`: 재판 CG, 그리고 실제 사용한 플래그만 회상.
- 마왕 등록 이의신청/급여청구/지원금 수령 후 47세 조건부 문장이 서로 충돌하지 않는지.
- v4.3의 새 엔딩 12개는 여전히 엔진에 실제 도달 경로가 필요한지 확인. 도달을 정적 파일 존재 여부로만 '통과' 처리하지 말 것.
- 기존 엔딩 8개 포함 총 20개: 도감에 획득 후 상세 그림·설명·본문; 미획득 스포일러 차단; 엔딩 화면에서 옛 SVG 대체 여부.
