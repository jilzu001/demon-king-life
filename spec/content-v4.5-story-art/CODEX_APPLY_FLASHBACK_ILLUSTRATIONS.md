# 코덱스 적용: 주마등 회상 일러스트 (v3.6 추가 패치)

## 적용
- 이 ZIP은 v3.6 통합 패키지 전체와 `assets/flashback/` WebP 10장을 포함한다.
- 이미지 10장은 **한 장의 AI 생성 콘셉트 시트에서 각각 잘라낸 컷**이다. 개별 고해상도 원화 10장이 아니며, 작은 컷은 확대하면 선명도가 떨어진다.
- `assets/flashback/flashback_manifest.json`의 크기를 확인하고 원본 픽셀 크기보다 크게 렌더링하지 말 것. CSS `max-width: min(100%, var(--asset-natural-width))`, `height:auto`, `object-fit:contain`. 고밀도 화면에서는 오히려 더 작게 표시해도 좋다.
- 21세 왕실 초대 회상에는 `fb_04_royal_invitation.webp` 또는 큰 왕궁 컷 `fb_10_royal_hall_wide.webp`가 적합하다.
- 모든 사건에 이미지를 강제하지 말 것. **실제 플레이어가 방문한 사건 중 감정적으로 중요한 기억 4~8개**만 회상. 관련 이미지가 없으면 기존 텍스트/아이콘 회상 유지.
- 이미지는 감성 연출용이다. 회상 문구는 실제 저장된 사건의 나이·선택·결과를 바탕으로 생성하고, 예시 시트의 나이·대사를 게임 정사로 쓰지 말 것.
- 이미지 선택은 이벤트 ID/캐릭터/감정 태그로 명시적 매핑. 단순 키워드 우연 매칭 금지. 선택하지 않은 선택지의 결과를 보여주지 말 것.
- 현재 엔진을 실제로 수정한 ZIP이 아니라 **코덱스가 통합할 리소스와 적용 지침**이다. 기존 저장/엔딩/분기와 모바일 레이아웃을 보호하고 테스트.
- 파일명이나 이미지 메타에 있는 `training`, `danger` 등은 제안 태그이지 새로운 정식 사건을 추가하라는 뜻이 아니다.

## 검증
1. 모든 WebP가 열리는지 확인.
2. 회상에 실제 플레이하지 않은 사건이 표시되지 않는지 확인.
3. 회상 이미지가 원본보다 확대되지 않는지 확인.
4. 모바일에서 자막과 이미지가 겹치지 않는지 확인.
5. 이미지가 없는 경우 기존 연출로 정상 폴백하는지 확인.
