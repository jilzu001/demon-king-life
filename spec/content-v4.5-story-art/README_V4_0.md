# 가짜 마왕의 일생 — v4.0 반복 집필 통합본

**v3.9 누적 패키지 전체를 포함**한 집필 중심 버전이다. 이 ZIP 하나로 소스/스토리/문서/기존 일러스트를 이어받을 수 있으나, *코드 저장소에 이미 적용됐음을 의미하지 않는다.*

## 변경 요약

- 확장 사건 본문 41개 추가/교정
- 확장 선택 후 결과 26개 강화
- 엔딩 8개 전면 확장
- 장기 선택 후폭풍 콜백 총 58개(이전 24개)
- 틀린 진입 조건과 유실된 엔딩 시네마틱 수정
- 총 56개 WebP 유지; 이미지의 시각적 통일을 고친 것은 아님

## 품질 점검 결과

`python audit/validate_v4_0.py`로 데이터 구조, 조건 참조, 최소 선택지, 문단 배열 동기화, 엔딩/시네마틱 연결을 검사한다.

**아직 하지 않은 것:** 실제 게임 엔진에서의 자동 이벤트 삽입, 20세 선택지 4개 UI, 저장 호환성, 이미지 캐릭터 동일성, 분기별 최종 정서 리딩 테스트. 완료로 간주하지 말 것.

더 자세한 변경 ID는 `audit/ITERATIVE_WRITING_REVIEW_V4_0.json` 참조. 기존 v3.9 이하 CODEX 문서는 참고 이력일 뿐이며 아래 최신 인계 문서가 우선이다.
