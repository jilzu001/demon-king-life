# 집필 진행 기록 — v4.0 (누적 통합본)

이 파일은 최신 릴리스 기준으로 편집 범위와 아직 구현되지 않은 부분을 구분한다. 이전 28/65 집중 보완률을 문학적 완성도로 해석하지 않는다.

## 이번 회차 진행: 자체 편집·재검토 5회

1. **논리/인물 일관성:** 고백하지 않은 경로에도 고백했다고 말하는 사과 장면 수정, 주인공과 미나의 동의·거리 표현 정리.
2. **장면 밀도:** 확장 사건 중 짧거나 추상적인 부분을 개별 상황·행동·갈등으로 보완.
3. **선택의 인과:** 짧은 결과문에서 눈에 보이는 대가 또는 다음 행동을 보강.
4. **엔딩 재집필:** 8개 엔딩을 장면·대사·회고가 있는 길이로 집필하고 누락된 엔딩 시네마틱을 보충.
5. **교차 검증:** 교도소/빵집 진입 조건, 이미 삭제된 엔딩 ID, 노년 확장 사건 시점, 데이터 참조 무결성 검사.

## 누적본 상태

- 핵심 사건 **16개**, 확장 사건 **65개**, 엔딩 **8개**를 유지한다.
- 확장 사건은 모두 기본 본문을 가지고 있고 선택지 최소 2개 이상이다. 새 재집필 본문의 자세한 ID 목록은 `audit/ITERATIVE_WRITING_REVIEW_V4_0.json`에 있다.
- 과거 `28/65 집중 보완` 표기는 **v3.6 당시의 작업 이력**이다. 이번 기준과 합산하지 않는다.
- **문학적 완성도 100%로 선언하지 않는다.** 반복 테스트에서 읽는 재미는 실제 사용자 평가가 필요하다.
- 현재 가장 시급한 남은 일은 실게임 플래그 연동 및 연령 점프 시 확장 사건 노출 확인이다.

## 절대 유지할 요소

- 스무 살 미나 실기 시험에 `미나에게 사랑한다고 고백한다.` 선택지가 존재한다.
- 선택 결과는 기존 choice ID, ending ID를 보존한다.
- 47세 법무관의 5만 골드 합의 / 관리예산 200만 / 실제 가족 지급 3천 / 차액 199만 7천 골드 — **차액은 유용 확정이 아닌 조사 대상**이다.
- 회상은 실제 방문한 사건만 표시하며 선택이 달라져도 허위 회상은 생성하지 않는다.
- NPC 초상화/일러스트 파일은 이 집필 버전에서 교체하지 않았다.
