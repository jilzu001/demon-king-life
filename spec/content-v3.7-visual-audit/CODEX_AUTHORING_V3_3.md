# v3.3 작가 집필 패치

기존 v3.2 콘텐츠를 기반으로 `content/events_v2_9.json`의 `first_wage`, `queen_letter`, `new_demon` 세 사건 본문 및 선택 결과를 전면 재집필했다. **나머지 62개 사건은 변경하지 않았다.**

- 대사와 서술은 `bodyParagraphs`와 `resultParagraphs`를 우선 사용해 문단 단위로 렌더링한다. 본문과 대사 카드를 중복 출력하지 않는다.
- 이벤트 ID, 선택 ID, 조건, 효과, 연대기, 저장 키는 유지한다.
- 원작 플레이는 복구하지 않는다.
- 기존 1~2회차, 저장/불러오기, 엔딩 도감, 타이틀 복귀 기능을 보호한다.
- 변경된 3개 이벤트의 선택 결과를 실제 화면에서 테스트한다.
