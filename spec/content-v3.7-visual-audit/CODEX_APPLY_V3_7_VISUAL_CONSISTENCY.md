# v3.7 코덱스 적용: 전 이미지 일관성 전수검사 및 NPC 초상화 로직

## 중요: 현황을 사실대로 처리
이 ZIP은 v3.6.1의 모든 콘텐츠/이미지를 보존하며 **자산 목록 전수 검사와 매핑·적용 지침**을 추가한다. 기존 이미지의 캐릭터 얼굴을 전부 새로 그려 수정한 ZIP은 아니다. 현재 서로 다른 이미지 시트에서 나온 캐릭터의 외형 불일치가 존재할 수 있다. 실제 프로젝트를 확인해 동일 인물 여부를 검수해야 한다. 외형이 안 맞으면 이미지 억지 연결 금지, 일단 해당 장면 이미지를 숨기고 이슈 목록에 남긴다.

## 순서
1. 현재 프로젝트의 실제 이미지 파일 경로와 `audit/VISUAL_ASSET_INVENTORY_V3_7.json` 목록을 대조한다. 게임 내 초상화/이벤트CG/주마등/엔딩/상태창/NPC 대화창에서 **각각 실제로 어떤 이미지가 나오는지** 확인한다.
2. `assets/visual_identity_rules_v3_7.json`을 캐릭터 정체성의 기준으로 활용하되, 그림 자체의 외모가 같은지는 직접 검수한다. 동일 인물로 확신할 수 없는 그림은 사용하지 않는다.
3. 미나를 최우선: 메인 상태창, 12세 나무칼, 20세 용사 시험, 추억, 엔딩에서 **머리색·눈색·앞머리·얼굴형·의상·연령 변화**가 자연스러운지 비교. 일관성이 없으면 canonical 미나 초상화 또는 이미지 생략으로 폴백한다. 기존 이미지들을 강제로 같은 인물로 간주하지 않는다.
4. 주인공, 에리시아, 국왕, 레온 등 실제 등장 NPC도 같은 방식으로 전체 점검한다. 레온은 현 패키지 캐릭터 목록에 확정 초상화가 없으므로 **다른 캐릭터 그림을 임의로 레온이라 부르지 말 것**.
5. NPC 초상화: 이벤트의 실제 speaker/actor/character ID를 기준으로 매칭한다. 내레이션에서는 마지막 대사자의 초상화가 남아 있지 않게 한다. 대화자 변경 때 즉시 변경. 존재하지 않는 캐릭터·이미지·상황이면 기본 아이콘 또는 초상화 숨김. '미나' 대사에 다른 캐릭터 얼굴 금지.
6. 감정 변화는 **동일 인물임이 검증된 표정 자산만** 적용. `assets/illustrations/expressions/*`는 캐릭터 정체성이 확인되지 않은 공용 시트 조각이므로 캐릭터 초상화 대용으로 사용 금지.
7. 주마등/엔딩은 실제 플레이에서 방문한 사건 및 선택 결과만. 이름이나 분위기가 비슷하다는 이유로 다른 인물 그림을 끼워넣지 않는다. 시트에 적힌 예시 나이/제목을 정식 스토리로 간주하지 않는다.
8. 이미지는 고유 픽셀 크기 이하로 표시하고 object-fit: contain, 가로세로비 유지. 모바일에서 강제 확대 금지. 원본이 작거나 흐리면 새 고해상도 자산이 만들어질 때까지 작은 크기 유지/생략.
9. 핵심 20세 시험의 '미나에게 사랑한다고 고백한다.' 선택지가 실제 데이터와 UI에 모두 나타나는지 재검사한다. 기존 선택지를 제거하지 않는다.
10. 기능 변경 후 기존 저장, 분기, 엔딩, 회상 4~8개, 화면별 NPC 교체, 모바일/PC 테스트. 테스트하지 않은 항목은 완료라고 표시하지 않는다.

## 코덱스 최종 보고 요구
- 모든 이미지별 파일명, 사용 화면, 묘사 인물, 동일 인물 검수 결과(PASS/FAIL/UNKNOWN), 조치
- 특히 미나의 메인 초상화↔이벤트↔주마등↔엔딩 비교 스크린샷
- NPC 초상화의 등장/퇴장/화자 전환 테스트
- 교체한 파일/숨긴 파일/미해결 목록과 저장 호환성 테스트
- 검증된 결과만 DEV_PROGRESS.md/CHANGELOG.md에 기록

## 디자인 기준
동일 캐릭터의 헤어 실루엣, 눈동자, 얼굴형, 기본 의상, 대표 색상 유지. 단순 배경·확산광·선명한 윤곽·저용량 WebP. 캐릭터별 연령 변화는 명시적 설정이 있을 때만. 생성된 '일러스트 가이드 포스터'의 예시 이름이나 얼굴을 실제 등장 인물로 임의 확정하지 말 것.
