# 《가짜 마왕의 일생》 v3.3 + 웹툰 일러스트 통합 패키지

## 우선순위
1. 기존 v3.3 콘텐츠 및 기능을 그대로 보존한다. `CODEX_AUTHORING_V3_3.md`와 선행 문서를 먼저 읽는다.
2. `assets/assets.json`에 45개의 신규 저용량 WebP가 있다. 이미지 경로는 이 파일을 단일 기준으로 사용한다.
3. **일러스트를 적절한 장면에 연결하되, 기존 JSON ID, 분기, 엔딩, 조건, 저장 스키마를 임의 변경하지 않는다.** 실제 프로젝트 코드 구조를 확인해 매핑을 구현한다.
4. 캐릭터 초상은 해당 인물이 등장하는 대화/장면에, 배경은 위치가 맞는 장면에, 사건 CG는 해당 사건에서만 표시한다. 일러스트가 없는 사건에는 임의로 엉뚱한 CG를 재사용하지 않는다.
5. 이미지에는 텍스트가 일부 포함될 수 있으므로 UI의 문구는 항상 HTML 텍스트로 별도 표시하고, 이미지에 포함된 글자는 장식으로만 취급한다. 인물 초상과 CG는 **동일한 원본 시트에서 분할한 그림**이므로 장면 전용 독립 일러스트와는 다르다.
6. 화면별 이미지 크기를 제한하고 `loading="lazy"`, `decoding="async"`, 너비/높이 지정, 적절한 캐싱을 적용한다. 첫 화면 핵심 이미지만 우선 로드한다.
7. 저장/불러오기, 1·2회차 해금, 연대기 한 줄 요약, 본문 빈 줄, 엔딩 갤러리, 타이틀 복귀, 모바일 화면을 회귀 테스트한다.
8. 적용 결과와 미연결 에셋 목록을 보고한다.

## 구성
- `assets/illustrations/characters/` : 인물 11종
- `assets/illustrations/backgrounds/` : 배경 8종
- `assets/illustrations/events/` : 사건 CG 8종
- `assets/illustrations/expressions/` : 표정 10종
- `assets/illustrations/ui/` : UI 8종

**주의:** 일부 이름은 시트 생성 과정에서 새로 붙은 시각적 별칭일 수 있으므로 기존 세계관의 공식 등장인물로 자동 추가하지 말 것. 기존 설정에 없는 캐릭터는 사용하지 않아도 된다.


## v3.4 추가 지침 — 메인 스토리 화면 본문 중간 일러스트

**메인 화면은 텍스트만 길게 나열하지 말고, 적합한 사건에서 일러스트를 본문 흐름 중간에 삽입한다.** 이미지 자체가 목적이 아니라 웹소설 몰입감을 높이는 장치다. `assets/main_screen_illustration_policy.json`을 적용 기준으로 사용한다.

- 사건 CG가 정확히 맞으면 **도입 문단 뒤 ~ 선택지 앞**의 자연스러운 문단 경계에 1장만 표시한다. CG가 없으면 등장 인물 초상 또는 장소 배경을 맥락에 맞게 선택한다. 맞는 그림이 없으면 **텍스트만** 보여준다. 모든 사건에 억지로 이미지를 배치하지 않는다.
- 메인 본문 영역의 넓이를 유지한다. PC에서 그림은 최대 폭 680px/높이 360px, 모바일은 가로 100% 이내/높이 240px 이내로 제한하며 원본 비율을 유지하고 강제 크롭을 피한다. 본문 문단 및 대사 사이의 빈 줄(`\n\n`)은 그대로 유지한다.
- **한 줄 연대기에는 이미지를 넣지 않는다.** 대사 카드 중복 생성 금지. 선택 버튼 안에도 이미지를 넣지 않는다.
- 동일 장면에서 그림 여러 장을 쌓지 않는다. 스토리 진행 시 화면이 과하게 점프하지 않도록 width/height 또는 aspect-ratio를 미리 예약한다. 첫 화면에서 보이는 그림만 우선 로딩하고 나머지는 lazy loading 한다.
- 이미지 경로는 `assets/assets.json`에서만 참조하고, 누락/실패 시 본문만 정상 출력한다. `alt`는 이미지의 의미에 따라 설정한다.
- **선택지/조건/엔딩/세이브 스키마를 수정하지 않는다.** 엔진 구조에 맞춰 별도 프레젠테이션 계층에 장면별 이미지 연결을 구현하고, 실제 인물과 무관한 별칭 캐릭터를 새로 생성하지 않는다.
- 회귀 테스트: 모바일/PC에서 첫 장면, 미나 시험장 고백, 재판, 엔딩, 그림 없는 장면, 저장 후 복귀. 그림이 본문을 밀어 선택지가 사라지거나 한 줄 연대기가 늘어나지 않는지 확인한다.
