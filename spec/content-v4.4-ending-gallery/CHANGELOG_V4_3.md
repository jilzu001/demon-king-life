# v4.3 — 1차 엔딩 12개 + 저용량 엔딩 일러스트

## 누적 기준
v4.2 ZIP 전부를 계승. 기존 8개 엔딩, 핵심 장면 16개, 확장 사건 65개, 연간 한 문장 후보 325개, 기존 이미지 56개는 삭제하거나 덮어쓰지 않았음.

## 신규 집필
- 12개 추가 엔딩 본문(장면형), 각 엔딩 finalScene·reflection 작성.
- 조건이 겹치거나 곧바로 엔딩으로 점프하지 않도록 엔딩별 선행 플래그 + 추가로 선택/획득해야 할 플래그를 분리.
- 엔딩 직전 최종 선택 2개씩, 총 24개 집필 (독립 bridge scene: engine integration required).
- 결혼은 고백만으로 불가, 상호 동의와 세월 필요. 미나가 용사가 됐는지/시험을 포기했는지 경로 구분.
- 횡령 미확정인 199만7천 골드는 회계상 행방 조사 대상으로만 취급.

## 신규 일러스트
- 12장 640×360 WebP: 기존 캐릭터 초상화를 재사용해 **외형이 동일한 기억형 콜라주**로 구성.
- 새 AI 콘셉트 시트는 캐릭터 외형 불일치로 미승인, 게임 에셋으로 포함하지 않음.
- 나이든 캐릭터의 젊은 초상화는 현재 얼굴이 아니라 회상 프레임으로만 사용. 고령 외형 신규 제작은 추후 별도 승인 후 교체.

## 엔진 적용 전 반드시
