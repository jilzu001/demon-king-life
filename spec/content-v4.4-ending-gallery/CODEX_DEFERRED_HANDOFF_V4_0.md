# 향후 단일 통합 적용용 Codex 인계 (지금 실행 필수 아님)

## 안전 절차

1. 저장소의 실제 HEAD, 콘텐츠 로더, UI 및 버전 관리 문서를 읽는다. 패키지가 최신 저장소라고 가정하지 말 것.
2. 우선 `README_V4_0.md`, `WRITING_PROGRESS.md`, `audit/ITERATIVE_WRITING_REVIEW_V4_0.json`과 `audit/validate_v4_0.py`를 검토한다.
3. 기존 레포에서 사용 중인 최신 story/chapter/events/endings와 선택지·ID를 비교한 뒤 **변경 필드만 안전하게 병합**한다. 리셋·삭제 금지.
4. 조건 이벤트 엔진이 `{all:[{hasFlag:"..."}]}`를 실제 해석하는지 확인하고, 교도소/빵집 조건을 테스트한다.
5. 신규 콜백은 `content/narrative_callbacks_v3_9.json`에 추가된 집필 데이터다. 콜백 엔진이 없다면 자동 작동한다고 보고하지 말고, 안전하게 통합하거나 미구현 표시한다.
6. `story.json` 초기 age=20과 첫 birth 노드 age=0 충돌이 있다. 실제 나이 초기화가 노드 기반인지 확인하고, 필요할 때만 마이그레이션 포함하여 수정.
7. 47세→65세 등 코어 노드 연령 점프 사이에 확장 이벤트가 스케줄되는지, 노년 이벤트 61~65세가 선택 경로에서 도달 가능한지 플레이 테스트.
8. 스무 살 시험의 4개 선택지(특히 `미나에게 사랑한다고 고백한다.`) 표시/결과/장기 분기 확인.
9. 주마등은 `onlyVisitedEvents=true`, 해당 실제 사건만 허용. 없는 추억을 만들어 보여주면 안 됨.
10. `ending_love_scandal`의 시네마틱 신설은 기존 end card/gallery와 충돌 없이 연결. 이미지 `mina_romance`는 기존 파일로서 외형 통일 작업 아님.
11. 캐릭터 초상화/NPC 화자별 렌더링 문제는 이 ZIP에서 해결했다고 말하지 말 것.
12. 실제 동작 테스트(최소 4개 핵심 경로 + 초반 비감옥 경로 + 조기 엔딩 + 빵집 없는 루트 + 재플레이 unlock)를 수행하고 수치/로그/한계 보고.
