# Codex 통합 작업서 — v3.9 전수 집필 편집본

## 원칙
1. 본 ZIP은 **v3.8 누적 전체 패키지 기반**이다. 81개 사건에 직접 편집이 반영되어 있다. 그러나 실제 저장소의 최신 상태가 더 앞서갈 수 있으니 반드시 diff와 원본 백업을 먼저 수행할 것.
2. `chapters/01_complete.json`, `content/events_v2_9.json`의 집필 수정은 **내용별 병합**으로 적용. 기존 사건/선택지 ID, 선택 효과, 엔딩 연결, 일러스트 매핑과 저장 호환성 보존.
3. v3.9에서 **65개 확장 사건 본문과 선택 결과 195개를 편집**, 16개 핵심 사건 본문과 핵심 선택 결과 43개를 보완했다. 중복된 이전 초안 39건을 제거했다. `audit/V3_9_WRITING_AUDIT.json`에서 수치를 우선할 것.
4. 시험 장면 `exam`에는 기존 `confess`,`stand_ground`,`absurd_invoice`를 보존하고, 기존 화면에 있던 직접 공격 선택 `attack_mina`를 새로 추가한 총 4개가 있어야 한다. `confess` 문구는 정확히 **`미나에게 사랑한다고 고백한다.`**이다.
5. `content/narrative_callbacks_v3_9.json`은 **새로 집필된 연속성 장면 사양**이다. 아직 실제 엔진이 지원하는지 확인되지 않았다. 핵심/확장 각 이벤트의 `body` 뒤, 선택지 전에서 **실제 저장 플래그가 있을 때만 해당 문단을 한 번 표시**하도록 구현할 것. 해당 사건을 경험하지 않았다면 주마등에도 넣지 말 것. 조건부 문단을 `body`와 `bodyParagraphs`에 중복 삽입하지 말 것.
