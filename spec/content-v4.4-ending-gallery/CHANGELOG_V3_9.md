# v3.9 누적 집필 검토 변경 사항

- **기준 버전**: v3.8 선택지 보완 통합 ZIP (이전 버전 파일·WebP 포함).
- **본문 편집**: 확장 65건 모두 개별 추가 장면 및 문장 다듬기, 핵심 16건 모두 개별 추가 장면 작성.
- **중복 정리**: 확장 본문 속 중복된 이전 초안 39건 제거.
- **결과 집필**: 확장 선택 결과 195건 전면 재집필, 핵심 선택 이후 서술 43건 개별 강화.
- **선택지 검수**: 전체 81개 선택 가능 사건에 최소 2개 선택지 유지. 20세 시험에 `attack_mina` 추가, 총 4개 선택지(공격/항의/출연료/고백); `confess` 선택지 정확한 문구 보호.
- **연속성 수정**: 12세 우물 사건 중복, 가족 3천 골드 지급 사실, 감옥·용사 자격 분기별 증언 충돌, 평온한 엔딩의 메타 서술, 공주 대관 분기 충돌 등.
- **후폭풍 집필 사양**: 어린 시절의 안전협약, 어머니의 반려 민원, 시험 고백과 미나의 거리, 왕실 감사의 날짜 등이 훗날 재등장하는 조건부 장면 24건 제공. *엔진 실행은 Codex 작업 필요.*
- **불변 사항**: 사건 ID, 기존 선택지 ID/효과/연결, 기존 엔딩, 기존 이미지와 UI 지침, 저장 호환성 보호.
- **검증**: 소스 정적 검증 완료. 게임 저장소에 적용한 실행·분기·UI 테스트는 미실시.
