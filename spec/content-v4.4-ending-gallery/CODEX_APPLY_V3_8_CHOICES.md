# v3.8 선택지 최소 2개 보완 — Codex 적용

- 기준: v3.7 전체 패키지에 `chapters/01_complete.json` 보완. 기존 노드 16개 중 선택지 1개인 5개 노드(birth, child, quiet, final_trial, office)에 7개 선택지를 추가했다.
- `content/events_v2_9.json`의 확장 사건 65개는 모두 선택지 3개라 수정하지 않았다.
- 기존 선택지 ID, 기존 연결, 원래 결과, 저장 플래그는 변경하지 않았다. 신규 플래그만 추가했다.
- 엔딩 직전 세 장면의 신규 선택지는 기존 엔딩으로 연결되지만, 선택별 결과 서술과 기록 플래그가 다르다. 엔딩 본문이 해당 플래그를 반영하도록 개선 가능하며, 실제 반영 전에는 연출 분기로 표시할 것.
- Codex는 실제 저장소의 최신 데이터와 비교 후 신규 선택지만 안전하게 병합할 것. 파일 전체를 무조건 덮어쓰지 말 것.
- 실제 렌더러가 2~4개 이상의 선택지를 모두 표시하는지 테스트. 특히 20세 미나 시험의 `미나에게 사랑한다고 고백한다.`가 화면에 노출되는지 확인.
- 각 신규 선택지 클릭 시 결과 본문, 플래그, 다음 사건, 새 게임/기존 저장 로드가 정상인지 검증.
- 선택지 0개인 엔딩 결과 화면과 단순 전환 화면은 별도 유형으로 구분하고, 선택 가능한 사건의 선택지 1개가 다시 발생하지 않게 자동 검사 추가.
- 기존 캐릭터/일러스트/주마등/엔딩/저장 기능 유지.
- 실제 플레이 테스트 결과와 예외 목록을 보고할 것.
