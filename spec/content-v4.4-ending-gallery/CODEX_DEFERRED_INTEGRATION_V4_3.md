# CODEX에 최종 누적본 전달할 때: v4.3 엔딩 1차 확장

아직 Codex에 넘기지 않고 콘텐츠 누적 중이라는 사용자 의사를 존중한다. 사용자가 '최종 적용'을 요청한 시점에만 다음을 수행한다.

1. 프로젝트 원본/현재 브랜치를 백업하고 repo의 최신 story, endings, cinematic, images, tests를 조사.
2. v4.2 대비 v4.3 변경만 병합. 기존 8개 엔딩과 모든 이전 플래그, 챕터 노드, 연간 단문 기록 325개를 보호.
3. `content/ending_routes_v4_3.json`, `content/ending_bridge_scenes_v4_3.json`, `content/ending_setup_scenes_v4_3.json`의 새 플래그/분기 필요 조건을 읽고 **실제 게임에서 가능한 경로로 구현**. 사전 플래그만으로 자동 엔딩 발생 금지. 사용자가 최종 선택을 해야 종료.
4. 추가 플래그 취득용 신규 중간 사건을 최소 하나 이상 per route로 넣되, 나이 건너뛰지 않도록 기존 연간 무선택 기록과 연동. 미나 결혼은 서로의 명시적 동의와 긴 신뢰 축적이 있어야 함.
5. 왕국 파산은 개별 199만7천 골드 횡령 단정 금지. 단체 피해배상 규모로 개연성 정리.
6. 신규 이미지 12종은 모두 **기존 정체성 확인된 초상화로 합성한 임시 엔딩 아트**. 캐릭터를 다른 얼굴로 갈아끼우거나 오버스케일 금지. 이미지를 가로 640 이하 원본 크기 이내로 표시. 고령 캐릭터 얼굴을 현재 모습으로 오인하지 않도록 회상 프레임 취급.
7. 기존 8개 + 신규 12개 엔딩 모두 결말 도달 루트 자동 테스트. 같은 플레이에서 서로 모순되는 ending 우선순위 방지. 조기 사망 이후 나이 증가 X, 20세 고백 4번째 선택지 보존, NPC 화자 초상화 매칭, 주마등은 실제 방문 기록만. 엔딩 도감에서 신규 12개 모두 표시.
8. 새로 추가한 버그/연속성 예외와 플레이 테스트 결과를 기록. 엔진에 적용하지 못한 라우트는 '미연결'로 표시하고 완성됐다고 보고하지 말 것.

## 스토리 변경 없이 먼저 점검할 것
기존 `story.json.initialState.age=20`와 출생 `birth.age=0`가 충돌할 수 있으니 새해 스케줄러의 나이 설정을 검사하라. 신규 12개 엔딩은 조건부 사이드카이므로 기존 8개 엔딩의 ID를 변경하지 말고 외부 조건과 최종 선택을 통해 진입하도록 하라.
