# 《가짜 마왕의 일생》 v5.0 — 콘텐츠 32개 엔딩 + 이미지 48장 코덱스 일괄 적용팩

## 이 ZIP의 실제 상태

- 새판 스토리: 47개 사건 / 106개 선택지·결과 / 8개 독립 인생 루트 / 32개 신규 엔딩. 기존 v5.0 집필 JSON 내용 유지.
- **새 판 사건 CG 12장:** 독립 생성 고화질 단독 장면 2장 + 합본 패널 크롭 저해상도 대체본 10장.
- **새 판 엔딩 CG 32장:** 합본 패널 크롭 저해상도 대체본 32장.
- **기존 사건 CG 재사용 후보 4장** 추가 동봉. 총 **WebP 48장**. 필요 신규 스토리 44장 중 이미지 없는 항목 0개.
- 사용자 요청으로 예전 합본 이미지를 패널별로 잘랐으며, 이는 **새로 42장을 독립 생성한 결과가 아님**. 원본 패널 약 170~330px를 720~768px로 확대했으므로 뿌옇게 보일 수 있음. 원본 해상도는 메타데이터에 기록함.
- 이미지 구도의 부정확함, 장면 오류는 있을 수 있으며 검수 전에는 최고 화질 일러스트라고 주장하지 말 것.
- 이 ZIP은 **실제 GitHub 코드에 아직 적용하거나 `npm run check`를 실행한 것이 아님**. 코덱스가 테스트·적용해야 함.

## 설치 순서

1. `docs/CODEX_PROMPT.md` 우선 읽기. 사용자의 로컬 수정분 및 방문 분기 색상 개선 보호.
2. `content/` 스토리 JSON 및 연동 작업 수행. 구버전 세이브/도감 데이터 분리.
3. `illustrations/asset_mapping.json` 사건 이미지 연결; `illustrations/ending_asset_mapping.json` 신규 엔딩 32개 연결.
4. **기존 공개 그림 중 동일한 장면의 고화질 CG가 있다면 크롭 대체본보다 우선**한다. 잘못된 합본 패널은 기존 좋은 이미지로 교체하거나 연결을 보류할 것.
5. `illustrations/*.webp`를 `artPath`에 해당하는 `public/` 하위 위치로 복사한다. 실제 파일이 있는지 확인 후 등록.
6. 새 엔딩 도감의 하드코딩 20개 제한 제거; 32개 새 엔딩 실제 ID로 동적 갤러리 구성.
7. 새 스토리 32개 엔딩 도달성, 신규 사건, 방문 색상 강조, 모바일 320/390/430px, 저장 호환 검증.

## 그림 관리

- 크롭 이미지 42컷은 모바일 소형 표시용 대체본. 원본보다 정밀한 장면 서사·인물 나이 일치를 보장하지 않는다.
- `docs/ILLUSTRATION_BRIEFS.json`은 장면별 원문 프롬프트를 유지하여 나중에 전용 고화질 그림으로 쉽게 교체할 수 있음.
- `docs/PROMPTS_FOR_HIGHRES_REPLACEMENT.json`은 향후 개선 후보용. 현재 파일 누락을 뜻하는 목록이 아님.
- `docs/ART_STATUS.json`과 `docs/CROP_MANIFEST.json`에 출처/용량/원본 패널 좌표를 기록함.
- 인포그래픽/라벨/검은 자막 막대가 게임 그림에 들어오지 않도록 크롭한 이미지 미리보기 `docs/ART_CONTACT_SHEET.jpg`로 확인.
- 메인 UI 전면 개편 및 BGM 추가 금지.
