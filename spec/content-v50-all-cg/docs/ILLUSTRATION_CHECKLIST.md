# CG 검수 기준 (합본 크롭 허용판)

- 사용자의 최신 지시로 **합본의 각 그림 패널을 분리해 저해상도 대체 CG로 허용**한다.
- 단독 장면 원본과 동급이라고 말하지 말 것. 원본 패널 해상도 약 170~330px. 업스케일로 디테일 복구 불가.
- 캡션·격자·상단 타이틀을 크롭 영역에서 제외했다. 임의 위치 검증은 `docs/CROP_MANIFEST.json` 참고.
- 사건 CG 12개 + 신규 엔딩 CG 32개 파일 모두 존재한다. 기존 재사용 후보 4개는 별도로 있음.
- 기존 게임의 고해상도 적합 일러스트가 있으면 그쪽을 우선 사용한다.
- 올바른 인물·나이·행동·이전 실제 선택이 맞는지 본문/엔딩 ID 단위로 점검한다. 캐릭터가 잘못 그려진 패널은 연결 보류 가능.
- WebP는 모바일 소형 표시를 우선한다. 원본 썸네일 품질의 한계 때문에 너무 크게 늘려 렌더링하지 않는다.
- 미획득 엔딩은 이미지 잠금을 유지. 방문한 사건에서만 본문 이미지를 출력.
- 새 그림을 AI로 재생성할 필요 없음. 재생성은 사용자가 별도 요청할 때만.
