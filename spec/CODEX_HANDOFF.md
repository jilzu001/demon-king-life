# 코덱스 최초 작업 지시

첨부된 `DEVELOPMENT_SPEC.md` 전체와 `CANON.md`를 먼저 읽어 주세요. `examples/`의 데이터와 `schemas/` 규격을 엔진 계약의 기준으로 삼으세요.

**이번 작업은 Phase 1만 구현하세요.**
1. Vite + TypeScript 프로젝트를 구성하세요.
2. JSON 콘텐츠 로더·조건 DSL·효과 DSL·seeded RNG·`choose` 원자적 전이 엔진을 작성하세요.
3. schema 검증과 상태 불변식 검사, DAG 참조 검사, 저장/복원과 예외 처리를 구현하세요.
4. 예제 스토리가 모든 루트를 엔딩까지 진행할 수 있게 아주 기본적인 웹 화면을 구성하세요.
5. 실행 명령 `npm run typecheck`, `npm test`, `npm run validate:content`, `npm run simulate:all`, `npm run build`를 준비하고 실제 통과 결과를 보고하세요.

중요: '선택은 시도이고 성공은 판정 결과'입니다. 임의 자동 성공이나 전투력 변경으로 스토리를 이어 붙이지 마세요. 예제 파일의 시간·인물 생사·법적 유죄 여부를 무단 변경하지 마세요.

기존 프로젝트가 있다면 파일을 전면 재작성하지 말고 현재 구조를 먼저 검사하고 영향 범위를 보고하세요. 완성 전에 25~40개 엔딩을 자동 생성하지 마세요. 이번 결과에는 구현 파일 목록, 테스트 결과, 확인된 남은 문제를 포함하세요.
