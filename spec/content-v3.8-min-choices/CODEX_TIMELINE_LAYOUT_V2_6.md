# 코덱스 필수 적용 — v2.6 한 줄 연대기 + 본문 영역 확대

## 화면 목표
- 현재 화면 상단의 **「나의 인생」 연대기**는 지나온 사건별 **한 줄 요약만** 보여준다. 본문을 잘라 붙이거나 대사를 발췌하지 않는다.
- `chapters/01_complete.json`의 각 노드에 새로 추가한 `chronicleSummary`를 사용한다. 이 필드는 **본문(`body`)과 별도로 작성된 한 문장**이며, 대사·줄바꿈·따옴표를 넣지 않는다.
- 예: `20세에 미나의 용사 시험에서 내가 제압 대상이 됐다.`
- 연대기 각 항목은 `나이 + 요약 한 문장`을 **한 화면 줄**로 표시한다. CSS `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;`를 적용한다. 긴 내용은 말줄임표로 처리하고 필요하면 `title`/접근성 레이블로 전문 제공. **연대기 자체는 본문이 아니다.**
- 연대기 항목은 실제 방문한 사건만 순서대로 표시한다. 미래·미방문 사건을 미리 노출하지 않는다. 현재 장면은 중복하여 연대기에 추가하지 말고, 선택 이후 확정된 방문 기록에 맞춰 기존 기록 방식과 일치시킨다.
- 기존 `history`에 본문이나 길게 잘린 문자열이 저장되어 있어도 표시할 때 `nodeId`로 원본 노드를 조회하여 `chronicleSummary`를 우선 사용한다. 기존 저장 데이터 마이그레이션이나 초기화는 하지 않는다.

## 메인 콘텐츠 공간 확대
- 모바일: 상단 인물·능력치 패널은 기존대로 유지하되 「나의 인생」 영역의 각 기록을 한 줄로 줄이고, 기록 전체의 높이를 제한한다. 연대기 컨테이너 `max-height: clamp(72px, 16vh, 130px); overflow-y:auto;`로 축소. 확보한 세로 공간을 현재 사건의 본문/선택지 영역에 돌린다. 긴 연대기는 내부 스크롤이나 `전체 기록` 버튼으로 확인한다.
- 데스크톱: 연대기 35% / 본문 65% 기존 구성이면 본문을 **최소 70%**, 연대기를 **최대 30%**로 바꾼다. 레이아웃이 다른 경우에도 본문을 더 넓게 배정한다.
- 본문을 `height`로 강제 잘라내지 않는다. 긴 본문은 스크롤 가능하고, 모바일에서 선택지까지 접근 가능해야 한다.
- `전체 기록` 버튼을 누르면 연대기 전체를 볼 수 있으나 기본 화면은 컴팩트 모드. 버튼 자체가 본문을 밀어내지 않도록 작게 배치.

## v2.5의 가독성 수정 유지
- 본문 `body`와 결과 `outcome.narrative`는 `\n\n` 기준으로 문단 분리 후 문단마다 여백 적용.
- 본문 대사를 별도 화자 카드로 **중복 출력 금지**.
- 스토리 문장과 연대기 요약을 합치지 말 것. `chronicleSummary`가 없는 레거시 장면에만 제목 또는 짧은 별도 요약을 사용하고 **본문 앞부분 잘라쓰기 금지**.

## 예시 CSS
```css
.life-timeline { max-height: clamp(72px, 16vh, 130px); overflow-y: auto; }
.life-timeline__item { display: flex; gap: .45rem; min-width: 0; align-items: baseline; }
.life-timeline__age { flex: 0 0 auto; }
.life-timeline__summary { min-width: 0; overflow: hidden; white-space: nowrap; text-overflow: ellipsis; }
@media (min-width: 900px) { .game-layout { grid-template-columns: minmax(0, 3fr) minmax(0, 7fr); } }
```
> `.game-layout` 및 클래스명은 실제 코드에 맞게 조정. 이 CSS는 구현 지침이지 자동 적용 패치가 아님.

## 완료 조건
1. 사진 속 `나의 인생` 기록은 항목당 딱 한 줄, 대사 없이 한 문장으로 표시된다.
2. 현재 이야기 본문 영역이 v2.5보다 넓거나 높아졌다.
3. 전체 기록 열기, 저장 복원, 분기 및 7개 엔딩이 유지된다.
4. 대사 사이 빈 문단 및 중복 대사 제거가 유지된다.
5. 모바일 실기기 폭 360~430px에서 스크린샷으로 확인한다.
