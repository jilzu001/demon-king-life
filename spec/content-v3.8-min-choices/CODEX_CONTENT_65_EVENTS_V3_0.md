# v3.0 — 신규 사건 62개 추가 / 총 65개 혼합형 사건

## 데이터
- `content/events_v2_9.json`에 기존 3개와 신규 62개, 총 65개 사건 수록. 기존 16개 코어 장면과 8개 엔딩은 `chapters/01_complete.json`, `endings.json`에 별도 보존.
- 각 사건은 고유 ID, 제목, 연령 범위, 한 줄 연대기, 본문, 세 가지 선택, 선택 결과, 플래그 효과를 갖는다.
- `conditional`은 현재 회차에서 조건 충족 시 후보로, `unlock`은 **첫 엔딩 이후 2회차부터** 후보로 삼는다.
- 엔진은 핵심 장면 사이에만 사건을 삽입하고, `oncePerRun` 및 연령 조건을 지킨다. 한 회차에 65개를 강제로 보여주지 않는다.
- 신규 사건은 `metaCompletedRunsGte: 1`로 해금하며, 일부 기존 사건에는 특정 엔딩 해금 조건이 있으므로 그대로 보존한다.
- `result`는 선택 직후 표시하는 서술이며 본문과 중복 렌더링하지 않는다. `body`와 `result` 모두 `\n\n` 문단 분리를 적용한다.

## 품질과 범위에 대한 정직한 안내
- 62개 사건은 각기 다른 상황과 선택지를 가진 **콘텐츠 초판**이다. 모든 사건에 개별 후속 장편 분기가 있는 것은 아니다. 특히 새로 추가한 사건은 선택 후 플래그를 남기고 코어 스토리로 복귀한다.
- **65개 사건은 기존 코어 장면 16개와 별도**다. 기존 엔딩과 저장 데이터를 훼손하지 않는다.
- 현재 `conditions`가 비어 있는 일반 조건부 사건은 캐릭터 생존·관계·시점별 상세 조건을 추가하기 전에는 서사적으로 부적합한 상황에 등장할 수 있으므로 코덱스는 실제 엔진의 상태와 연계해 적격성 검증을 구현해야 한다.
- 모든 신규 사건을 웹소설 장편 수준으로 검수했다고 주장하지 않는다. 데이터 스키마 검증과 실제 브라우저 플레이 검증은 구분한다.
