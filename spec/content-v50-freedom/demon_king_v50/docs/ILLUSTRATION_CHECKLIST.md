# 그림 제작·검수 기준

- 우선 GitHub `public/assets/illustrations` 와 코덱스 로컬 `.codex/generated_images` 를 비교해 **이미 완성된 장면**이 있는지 확인한다.
- PNG를 WebP로 압축하는 것은 새로운 그림의 생성이 아니다. ZIP에 실린 4장은 이전 대화에서 제작한 단독 일러스트 **재사용분**이다.
- `ILLUSTRATION_BRIEFS.json`의 장면 12개와 결말 32개는 **아직 제작되지 않은 그림**이며, 코덱스에게 AI로 생성하라고 하지 않는다. ChatGPT에서 장면 단위로 순차 제작 후 검수한다.
- 기존 승인이 확인된 0세 출생신고 이미지를 우선 사용한다. 스크린샷/패널에서 얼굴만 자르거나 인물 집합 그림을 조각내서 재활용하지 않는다.
- 생애 단계에 맞는 헤어스타일, 나이, 의상, 수염/주름을 사용한다. 마왕으로 태어난 아기의 부모는 20대 성인 주인공과 미나가 아니다.
- 인물, 배경, 사건 행동이 한 화면에서 자연스럽게 통합되어야 한다. 일러스트는 순수한 단일 장면이며 UI/글자/그리드/미니어처 콜라주가 아니다.
- 초상화/기존 일러스트의 경로를 우선 재사용하되, 그 장면과 실제로 같은 등장인물·사건일 때만 연결한다.
- 목표: 일반 CG 40~120KB(WebP 960px 폭), 모바일 320/390/430px에서 중앙 인물 확인. 과한 압축으로 번진 얼굴은 다시 인코딩.
- 새 이미지 파일이 없는 장면에서는 기존 공통 배경 또는 이미지 없이 텍스트만 표시한다. 엉뚱한 사진은 붙이지 않는다.
- **코덱스에서 이미지 생성 금지**. 여기서 승인한 WebP만 설치하고 새로운 아트 요청은 별도 자료로 보고한다.
