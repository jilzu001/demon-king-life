# 《가짜 마왕의 일생》 v5.0 — 자유 재집필/독립 인생 루트 팩

## 이번 납품물의 정확한 상태

- **새롭게 작성한 게임 엔진 형식의 콘텐츠 JSON**: 공통 시작 포함 사건 47개, 선택지 106개, 상이한 엔딩 32개. 기존 20개 엔딩을 목표나 보존 대상으로 취급하지 않았다.
- **경로 구조 검사 완료**: 중복 ID/목적지/시간 역행/순환/연결되지 않은 사건과 엔딩 검사, 모든 엔딩까지 864개의 선택 연쇄 열거.
- **실제 브라우저 체험판**: `preview/index.html`을 압축해제 후 열면 새 콘텐츠의 임시 플레이 가능. 이 체험판은 정식 프로젝트 엔진이 아니다.
- **일러스트 실물 4개**: 새로 생성한 그림이 아닌, **이전 대화에서 제작된 단독 사건 그림을 재사용해 저용량 WebP 변환한 파일**. 나머지 신규 CG 12개, 엔딩 32개는 구체적 프롬프트만 작성했고 **미제작**.
- **GitHub/로컬 프로젝트 적용 및 npm 테스트 미실행**: 파일을 갖춘 코덱스가 실제 프로젝트와 대조/적용/검증해야 한다.

## 설계

- 공통 도입: 출생신고(0세) → 미나와 만남(12세) → 용사 시험(20세).
- 이때 네 방향으로 갈라짐: 도주/저항, 법/개혁, 계약/정치, 미나/관계.
- 각 큰 방향에는 상호 독립된 하위 인생 두 개(총 여덟 개).
- 각 인생에는 서로 다른 중반 장면 2종, 후반 장면 2종, 엔딩 4개가 있다. **하위 인생 사이에 공통 사건으로 다시 합류하지 않는다.**
- 이전 선택은 플래그, 후반 조건부 연대기와 엔딩 회고로 회수. 선택마다 고유한 결과 서술을 제공.
- 이전 엔딩 20개는 이 새 판의 전제도 목표도 아니며, 새 판에서는 **32개 완전히 새 결말**을 사용한다.

## 폴더

- `content/story.json`, `characters.json`, `endings.json`, `chapters/*.json`: 바로 엔진 콘텐츠 계약에 맞춘 원본.
- `illustrations/*.webp`: 이전 대화에서 제작된 네 장의 재사용용 WebP.
- `illustrations/asset_mapping.json`: 출처·연결 사건·이미지 크기.
- `docs/ROUTE_MATRIX.json`, `ENDING_CATALOG.json`: 실제 새 8개 루트와 32개 엔딩 매핑.
- `docs/STRUCTURAL_CHECK.json`, `EXAMPLE_ROUTES.json`: 정적 연결 검사와 엔딩별 선택 예시.
- `docs/ILLUSTRATION_BRIEFS.json`, `ILLUSTRATION_CHECKLIST.md`: 일러스트 프롬프트·그림체·제작 대기 상태.
- `docs/CODEX_PROMPT.md`: 로컬 프로젝트에 적용할 Codex 지시서.
- `preview/index.html`: 압축해제한 폴더에서 여는 단순 체험판.

## 주의

- 로컬 Windows 경로는 원격 ChatGPT에서 직접 읽지 못한다. 현재 GitHub의 엔진 구조를 확인하고 생성했으나 로컬에 미커밋된 최신 코드를 덮어쓰지 않는다.
- 엔진은 새 32개 엔딩을 처리 가능하지만 도감 UI에는 기존 20개 고정 검사가 있다. UI/데이터 연동 변경이 필요하다. 이 변경을 ‘엔진 재개발’이라고 부르지 않는다.
- 기존 세이브는 기존 버전·스토리 계약으로 보존한다. 새 콘텐츠는 별도 버전·저장 슬롯. 조용한 저장 데이터 초기화/강제 마이그레이션 금지.
- 미완료 아트를 완료했다고 보고하지 않는다. BGM을 추가하지 않는다.
