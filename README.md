최신 v2.6 콘텐츠(13개 사건·28개 선택·7개 엔딩)를 실행합니다. 기본 주소와 바탕화면 실행 모두 현재 판으로 연결되며 원작 플레이 버튼을 제거했습니다. 독립 한 줄 연대기, 문단 여백, 선택 후 서술과 결말 화면을 제공합니다. **전체 기록 → 여기부터 재선택** 또는 설정의 **지난 분기에서 이어하기**로 현재 회차에서 방문한 사건의 선택 직전으로 돌아갈 수 있습니다. 재선택 후에는 새 경로로 이어지며 엔딩 도감은 유지됩니다. **재선택 전 회차 복원**으로 직전 회차도 되돌릴 수 있습니다. 상세 내용은 [재선택 보고서](docs/RESELECT.md)와 [콘텐츠 적용 보고서](docs/COMPACT_V2_6.md)에 있습니다.

## 보관된 원작 개발 기록

아래는 이전 원작의 기능/개발 기록입니다. 원본 JSON과 저장을 보관하며 공개 앱의 원작 플레이는 제거했습니다. 원작 UI 회귀 검사는 Playwright의 별도 로컬 `archived-ui` 모드에서만 실행합니다.

[바로 플레이](https://jilzu001.github.io/demon-king-life/) · [GitHub 저장소](https://github.com/jilzu001/demon-king-life)

첨부된 콘텐츠 v1.1의 98개 장면·340개 선택·363개 결과·34개 엔딩을 실행하는 정적 Vite + TypeScript 웹게임입니다. 이전 Phase 1 엔진을 유지하고, 실제 인생 기록·현재 사건·화자별 대화·원클릭 선택 UI를 적용했습니다. GitHub Pages에 공개 배포했으며 로그인이나 외부 AI 호출 없이 플레이합니다. 다른 게임 폴더를 수정하지 않았습니다.

타이틀 화면에서 시작/이어하기를 선택합니다. 플레이 화면의 상단에는 주인공 초상화·2×2 능력치·주요 NPC 영역을 두고, 아래에는 최근 연대기 3개와 GPT 대화창처럼 사건·대사를 표시합니다. **나의 인생** 옆의 **전체 기록**에서 방문한 장면을 다시 읽고, 하단 **설정**에서 저장 가져오기·내보내기와 엔딩 도감을 사용합니다. 화면은 휴대폰 높이에 맞게 반응형으로 구성하며 대화만 내부에서 스크롤합니다.

새 장면은 **연대기 → 본문 → 화자별 대사**를 천천히 읽을 속도로 한 줄씩 자동 표시합니다. **메인창 클릭 한 번에 다음 한 줄만 즉시 표시**하며, 새 줄을 읽을 시간을 준 뒤 자동 진행을 이어갑니다. 기본 속도는 약 6자/초, 짧은 줄도 최소 2.5초입니다. 마지막 대사의 읽기 시간이 지나면 선택 팝업이 열립니다. 하단 **빠르게**는 빠른 자동 표시를 켜며, 메인창 클릭은 다음 한 줄을 보여주고 기본 자동 속도로 돌아갑니다. **스킵**은 해당 장면만 즉시 펼쳐 선택하게 합니다. **잠시 내리기**로 팝업을 닫고 대사를 다시 읽은 뒤 **선택지 보기**로 복원할 수 있습니다. 위로 스크롤하면 이전 방문 사건을 한 개씩 불러옵니다. 하단에는 일시정지/재생·인물 상태·설정도 있습니다. 읽기·스킵·팝업·이전 사건 열람은 판정·확률·저장 데이터를 바꾸지 않습니다.

미나의 짧은 적갈색 머리와 에리시아의 긴 금발/땋은 머리 등으로 인물을 구분했습니다. 5명 × 4연령 × 5감정의 100종과 기본 표정 20종을 별도 128×128 WebP로 제공합니다. 초상화 전체 약 185KB, 배경 포함 약 354KB이며 필요한 사진만 로딩합니다. 연대기 중에는 오른쪽 NPC 영역만 배경으로 바꾸고 대사 단계에서 인물/표정으로 전환합니다. 초상화 연령은 작품 진행 단계의 화면 연출이며 NPC의 생년월일을 새로 정의하지 않습니다. [초상화 모음](https://jilzu001.github.io/demon-king-life/art/portraits/gallery.html)과 `docs/CHAT_UI.md`, `docs/portrait-prompts-v2.json`을 참고하세요.

이전 8장면 예제 세이브는 원래 회차를 이어갑니다. **새 회차 시작**부터 콘텐츠 v1.1을 플레이합니다. 전체 v1.0 형식의 저장은 원장·seed·최종 상태를 재검증해 버전만 이관합니다. 업데이트된 앱의 첫 실행에서 기존 회차·도감을 별도 저장 키로 백업한 뒤 저장을 처리하며, 설정에서 이전 회차 JSON을 내보낼 수 있습니다. 손상되거나 호환되지 않는 저장은 덮어쓰지 않습니다.

현재 작품의 작가 제공 정사는 `CONTENT_CANON.md`이며, 원래 엔진 예제의 `CANON.md`는 보존했습니다. 상세 적용 결과와 변경 범위는 `docs/CONTENT_V11_IMPORT.md`를 확인하세요.

## 실행

설정의 **화면 전체 글자 크기**에서 100~150%를 10%씩 조절합니다. 현재 기본 크기인 100%가 최솟값이며, 타이틀·능력치·연대기·대사·선택지·버튼·설정창의 모든 글자에 적용됩니다. 브라우저에 별도로 저장해 새로고침해도 유지하며 게임 세이브를 변경하지 않습니다.

Node.js 22.12 이상과 npm이 필요합니다. PowerShell에서:

```powershell
Set-Location 'C:\Users\jilzu\OneDrive\Codex\make_game_test\demon-king'
npm ci
npm run dev
```

표시된 로컬 주소를 브라우저에서 엽니다. `index.html`을 파일로 직접 열지 마세요. 콘텐츠 fetch와 모듈 로딩에는 HTTP 서버가 필요합니다.

바탕화면의 **가짜 마왕의 일생.lnk**를 더블클릭해도 실행할 수 있습니다. `Start-Game.ps1`이 빌드된 게임 서버를 숨김으로 시작하고 기본 브라우저에서 `http://127.0.0.1:4175/`를 엽니다. 이미 실행 중인 서버는 재사용합니다. 서버는 PC를 종료할 때까지 유지되며, 저장은 이 주소를 기준으로 유지됩니다. 시작 오류 로그는 `%LOCALAPPDATA%\DemonKingPhase1`에 있습니다.

```powershell
npm run typecheck
npm test
npm run validate:content
npm run simulate:all
npm run test:e2e
npm run build
```

`npm run check`는 위 검증을 순서대로 실행합니다. `build`도 타입·구조·전체 분기 검사 실패 시 중단합니다. 단위 및 브라우저 검사는 `check`에서 함께 실행합니다. 빌드 결과는 `dist/`이며 `npm run preview`로 확인할 수 있습니다.

브라우저 테스트는 Windows의 설치된 Edge를 기본으로 사용합니다. 다른 환경에서는 Chromium을 설치하고 채널을 지정합니다.

```powershell
npx playwright install chromium
$env:PLAYWRIGHT_CHANNEL = 'chromium'
npm run test:e2e
```

실제 배포 경로는 `/demon-king-life/`입니다. GitHub Actions가 `VITE_BASE_PATH`를 지정하고 전체 검증 뒤 `dist/`만 게시합니다. 로컬은 기본 루트 주소를 유지합니다. 자동 브라우저 테스트는 `/phase1-test/` 하위 경로를 사용합니다. 배포 절차와 실제 공개 주소 검증은 `docs/DEPLOYMENT.md`에 기록했습니다.

## 동작과 보호 규칙

- `choose(story, state, nodeId, choiceId)`가 조건 충족 결과만 추첨하고 복제된 상태에 효과를 적용합니다. 예외 발생 시 원본 상태와 RNG를 유지합니다. 자격 결과 0개는 콘텐츠 오류이며 다른 결과로 대체하지 않습니다.
- 확정 결과 하나에는 난수를 소비하지 않습니다. 여러 결과에는 가중 판정당 한 번 소비합니다. 렌더링은 효과나 난수를 실행하지 않습니다.
- `entryEffects`는 최초 진입과 같은 전이에 포함됩니다. v1 DAG에서는 재방문 자체를 거부합니다.
- 회차 저장은 `existence-sim:v1:run:demon-king`, 도감은 `existence-sim:v1:meta`입니다. 다음 상태 저장이 성공하기 전에 장면 전환을 완료하지 않습니다. 실패하면 입력을 잠그고 대기 중 상태 JSON 내보내기와 저장 재시도를 제공합니다.
- 가져오는 JSON은 1MB 제한, 문법·중복 키·스키마·버전·스토리·불변식을 검사하고 초기 seed부터 실제 선택을 다시 실행하여 최종 상태와 대조합니다. 이관표 없는 구 버전과 변조 저장은 거부하며 기존 저장을 보존합니다.
- 손상된 저장은 자동 초기화하지 않습니다. 사용자가 백업한 뒤 명시적으로 새 회차를 선택해야 교체합니다. 손상된 도감도 묵시적으로 지우지 않습니다.
- `simulate:all`은 확률에 관계없이 모든 조건 충족 결과를 실행합니다. 동일한 깊이와 세계 상태를 합치되 종단 경로 수를 누적합니다. 탐색 상한에 도달하면 실패합니다.
- 초기 전과는 없습니다. 제공된 v1.1 판결 결과 17개와 이전 예제의 두 판결을 검수 이벤트로 등록했습니다. 고발·구애·혼인·차액만으로 죄나 왕위 권리가 생성되지 않습니다.
- 실행용 v1.1 콘텐츠는 첨부 원본과 바이트 단위로 일치합니다. 새 문장이나 결과를 엔진에서 생성하지 않습니다. 이전 예제는 `public/stories/demon-king-legacy-phase1/`에 보관하여 구 회차에 사용합니다.

## 남은 범위와 제한

요청한 v1.1 콘텐츠·UI·CI/공개 배포를 완료했습니다. 향후 콘텐츠 편집 도구와 추가 작품은 별도 작업입니다.

서사의 법률·동기·내막은 문장에서 자동 추론할 수 없습니다. v1.1의 명시된 판결 17개와 동의한 혼인 사건은 `src/content/legal-events-v11.ts` 및 `policies.ts`에 연결했습니다. `married_erisia`는 제공된 작품의 혼인 플래그이며, 기존 예제의 등록/동의 플래그 검사도 유지합니다. 후속 법적 이벤트는 별도 검수와 테스트가 필요합니다. `presence/reference/flashback` 생사 검사는 지원하지만 메타데이터가 없는 본문 속 출현은 작가 검수가 필요합니다.

localStorage는 키 여러 개를 묶는 트랜잭션을 제공하지 않습니다. 쓰기 예외에는 이전 회차·도감 복구를 시도하고 복구 실패도 표시합니다. 도감과 회차 사이에서 브라우저가 강제 종료되는 경우까지 완전한 다중 키 원자성을 보장하지는 않습니다. 회차 자체는 상태·RNG·선택 원장을 단일 JSON으로 저장합니다. 도감은 별도 누적 기록이며 백업을 권장합니다.

설치된 Edge에서 PC 및 320px 모바일을 검증했고 360·390·430·768·1280px로 너비를 바꿔 레이아웃과 가로 넘침도 확인했습니다. CI에서는 Chromium으로 같은 테스트를 통과했습니다. 실제 공개 주소에서 PC/모바일의 3회 진행·복원과 19회 선택 후 엔딩·조기 사망 엔딩을 확인했습니다. 실제 휴대기기와 Safari/Firefox 검증은 별도입니다. 로컬 저장은 공개 주소로 자동 동기화되지 않으므로 설정에서 회차 JSON을 내보내고 공개 주소에서 가져오세요.

사용 라이브러리 문서: [Vite](https://vite.dev/guide/), [Ajv](https://ajv.js.org/json-schema.html), [Vitest](https://vitest.dev/guide/).
